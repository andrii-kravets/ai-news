## Новини
- **Arduino VENTUNO Q** — відкриті передзамовлення на дошку з Qualcomm Dragonwing IQ8 (до 40 TOPS NPU) та STM32H5 для real-time контролю. 16 ГБ LPDDR5, 64 ГБ eMMC, Wi-Fi 6, 2,5 GbE, HDMI 4K, M.2 для NVMe. AI-сторона — Ubuntu з Docker; Arduino App Lab об'єднує скетчі, Python та AI-моделі. Комерційні SOM-версії від партнерів повторюватимуть той самий software-стек. [Посилання](https://store.arduino.cc/products/ventuno-q)
- **Arduino App Lab 0.11** — нова версія IDE для VENTUNO Q: можна «відвантажувати» проект на інші сумісні дошки та додано розпізнавання об'єктів як вбудовану функцію. Орієнтована на тих, хто вже завершив перший проект на UNO Q. [Посилання](https://www.cnx-software.com/?p=167243)
- **Sixfab AI HAT+ для Raspberry Pi 5** — Sixfab та DEEPX у середині жовтня 2026 представили плату розширення з низькоспоживаним AI-акселератором для Pi 5. Дозволяє виконувати інференс моделей зору та мови безпосередньо на краю без хмари. [Посилання](https://news.tuxmachines.org/n/2026/10/20/Open_Hardware_Modding_Raspberry_Pi_Pimoroni_Arduino_and_More.shtml)
- **Synergy Logic SLM-RP4** — промисловий контролер на базі Raspberry Pi 4 із DIN-рейковим монтажем, UL-сертифікацією, підтримкою OpenPLC та до восьми стекуємих I/O-модулів. Перший RPi-based PLC із UL-listed статусом — знижує поріг входу в промислову автоматизацію для maker-спільноти. [Посилання](https://news.tuxmachines.org/n/2026/10/23/Open_Hardware_Modding_Arduino_Pimoroni_and_More.shtml)
- **Olimex: два нових open-source рівневих конвертери** — BB-LVL-SHIFT (для макетних плат) та UEXT-LVL-SHIFT (для екосистеми UEXT) — нові відкриті апаратні рішення для роботи з різною логікою (3,3 В / 5 В). Схеми та файли у відкритому доступі. [Посилання](https://news.tuxmachines.org/n/2026/10/23/Open_Hardware_Modding_Arduino_Pimoroni_and_More.shtml)
- **Make: Guide to Boards 2026 — Indie Boards** — Makezine опублікував щорічний огляд мікроконтролерних платформ з акцентом на незалежні виробники: нові альтернативи Arduino та Pi від малих команд, переважно з відкритим hardware-дизайном. [Посилання](https://makezine.com/article/technology/microcontrollers/guide-to-boards-2026-indie-boards/)
- **Raspberry Pi CM5 Jig** — Raspberry Pi випустила власний програматор-jig для прошивки Compute Module 5, зробивши доступнішою альтернативу $2,500 рішенню від Everypin. Спрощує batch-flash у виробничих умовах. [Посилання](https://hothardware.com/news/raspberry-pi-jig-tool-flash-hardware-faster)
