# Hardware / DIY Electronics Дайджест 2026-11-14

## Ключові тези
- Bambu Lab H3C tool changer: 9 інструментів в одному 3D-принтері — найбільша анонсована новинка тижня від лідера ринку
- ESP32-S31 отримав підтримку повноцінного Linux 6.18 — developer preview від Espressif
- Olimex UEXT-CH390: відкритий Ethernet-модуль для Pico та ESP32, схемотехніка на GitHub

## Новини

- **Bambu Lab H3C** — 3 листопада 2026 Bambu Lab анонсував tool changer з 9 змінними інструментами на борту. Означає перехід компанії в сегмент мультиматеріального/мультиметодного друку. [Voxel Matters](https://www.voxelmatters.com/the-next-bambu-lab-teaser-video-premieres-on-voxelmatters-on-october-23/)

- **QIDI MakeBuddy Smart5** — 10 листопада 2026 QIDI представила AI-принтер для домашнього використання в сімейному сегменті. AI-асистовані функції, автоматичний друк, освітній контент, мультиплатформне керування. [IBTimes UK](https://www.ibtimes.co.uk/qidi-makebuddy-smart5-family-3d-printer-launch-1831596)

- **Raise3D T450 та T700** — 10 листопада 2026 Raise3D представила два великоформатних FFF-принтери для індустріального застосування. Орієнтовані на виробничий сектор і освіту. [Voxel Matters](https://www.voxelmatters.com/)

- **ESP32-S31 — повноцінний Linux** — Espressif опублікував developer preview BSP для Linux 6.18 на ESP32-S31. Не рекомендовано для production, але відкриває нові можливості для embedded-проектів. Ядро доступне на GitHub. [MakeUseOf](https://www.makeuseof.com/your-esp32-can-now-officially-run-full-linux/)

- **Olimex UEXT-CH390 Ethernet** — відкритий SPI-to-Ethernet модуль для Raspberry Pi Pico, Pico 2 та кількох варіантів ESP32 (100 Mbps). KiCad-файли, схеми, прошивка та приклади — на GitHub. Також опублікований RP2040-драйвер для ESPHome. [Open Source For You](https://www.opensourceforu.com/2026/11/open-source-module-adds-ethernet-to-pico-and-esp32/)

- **ESPectre** — відкритий проект, що перетворює Wi-Fi-радіо ESP32 на датчик руху без будь-якого фізичного сенсора: аналізує channel state information (CSI). Підтримує ESP32, S2, S3, C3, C5, C6; доступний як ESPHome-компонент. [XDA Developers](https://www.xda-developers.com/turned-spare-esp32-into-motion-sensor-rooms-using-open-source-projects/)

- **Formnext 2026 (17–20 листопада, Франкфурт)** — EOS готується представити нову полімерну 3D-платформу, VECTRON покаже свою технологію публічно вперше. Повні деталі очікуються з 17 листопада. [Voxel Matters](https://www.voxelmatters.com/)
