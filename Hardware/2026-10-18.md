# Hardware / DIY Electronics Дайджест 2026-10-18

## Ключові тези
- Raspberry Pi випустила новий джиг-інструмент для швидкого прошивання Compute Module 5 — суттєво дешевше за аналоги
- Arduino UNO Q: перший UNO з AI-акселератором (3-TOPS NPU) та octa-core ARM
- Raspberry Pi OS 6.3 перейшла на композитор labwc; ESP3D прошивка для 3D-принтерів отримала v3.1.2

## Новини
- **Raspberry Pi CM5 Programming Jig** — Raspberry Pi випустила спеціальний провізійний пристрій для прошивання Compute Module 5: встановлює ОС, налаштовує secure boot та повне шифрування диска. Раніше єдиний аналог коштував ~$2500. [Посилання](https://hothardware.com/news/raspberry-pi-jig-tool-flash-hardware-faster)

- **Arduino UNO Q** — новий Arduino UNO з восьмиядерним ARM-процесором, 3-TOPS NPU, LPDDR5 оперативною пам'яттю, M.2 SSD, GbE та інтерфейсами для дисплеїв і камер. Дозволяє запускати AI-моделі прямо на платі без інтернету. [Посилання](https://news.tuxmachines.org/n/2026/10/02/Open_Hardware_Modding_Arduino_Raspberry_Pi_and_Lots_More.shtml)

- **Raspberry Pi OS 6.3 (15 вересня 2026)** — новий реліз змінив стандартний десктоп на легкий композитор labwc замість попереднього. Поліпшена сумісність з Wayland. [Посилання](https://en.wikipedia.org/wiki/Raspberry_Pi_OS)

- **ESP3D v3.1.2 (3 липня 2026)** — прошивка для ESP32/ESP8266-контролерів, що використовуються у 3D-принтерах: виправлено автентифікацію і завантаження файлів у UTF-8. Версія v3.1.0 раніше додала WebSocket-передачу файлів. [Посилання](https://github.com/luc-github/ESP3D/releases)

- **Prunt Board 3** — crowdfunded плата управління 3D-принтером із шістьма драйверами TMC2240, двома 15A виходами нагрівачів та унікальним 31-фазним профілем швидкості для плавнішого руху. [Посилання](https://news.tuxmachines.org/n/2026/10/07/Open_Hardware_Modding_Raspberry_Pi_Arduino_and_More.shtml)

- **ESP32 + 3D-друк: 5 weekend-проектів** — Yahoo Tech опублікував підбірку ESP32-проектів, які вимагають 3D-принтера: від кастомних корпусів до смарт-пристроїв. [Посилання](https://tech.yahoo.com/computing/articles/5-clever-esp32-weekend-projects-163014791.html)

- **Make: Guide to Boards 2026 — Indie Boards** — щорічний гайд Make Magazine по мікроконтролерам і одноплатниках виділив категорію «indie boards» — альтернативи великим платформам від незалежних виробників. [Посилання](https://makezine.com/article/technology/microcontrollers/guide-to-boards-2026-indie-boards/)

- **Pinetek IOL Core4** — промисловий модуль для підключення до чотирьох датчиків або актуаторів за стандартом IEC 61131-9 SDCI. Орієнтований на maker-DIY у промислових умовах. [Посилання](https://news.tuxmachines.org/n/2026/10/07/Open_Hardware_Modding_Raspberry_Pi_Arduino_and_More.shtml)
