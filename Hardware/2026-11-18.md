# Hardware / DIY Electronics Дайджест 2026-11-18

## Ключові тези
- Arduino випустив Uno Q — одноплатний комп'ютер після придбання Qualcomm
- Raspberry Pi розширює лінійку: Pi 500+, AI HAT+ 2, Compute Module 5
- Maker-краудфандинг б'є рекорди: лише Q3 2026 — $44,1 млн у категорії виробничих інструментів

## Новини

- **Arduino Uno Q** — після придбання Arduino компанією Qualcomm вийшов Uno Q: одноплатний комп'ютер з вбудованим мікроконтролером Arduino. Описаний у щорічному гіді Make: magazine. [Джерело](https://makezine.com/article/electronics/guide-to-boards-2026-super-tiny-computers)

- **Raspberry Pi 500+** — новий десктопний модуль, головний герой обкладинки Make: Volume 95 та офіційного Raspberry Pi Handbook 2026. Оновлена версія Pi 500. [Джерело](https://www.raspberrypi.com/news/the-official-raspberry-pi-handbook-2026-is-here/)

- **Raspberry Pi AI HAT+ 2** — модуль для запуску генеративних AI-моделей безпосередньо на Raspberry Pi 5, входить до 5 нових апаратних релізів 2026 року. [Джерело](https://www.electronicdesign.com/technologies/embedded/product/55403971/electronic-design-5-new-raspberry-pi-hardware-releases-in-2026)

- **Raspberry Pi Compute Module 5** — новий модуль для вбудованих застосунків; також у списку нових релізів поряд із Pi 4 3GB та Pi 5 1GB. [Джерело](https://www.electronicdesign.com/technologies/embedded/product/55403971/electronic-design-5-new-raspberry-pi-hardware-releases-in-2026)

- **Raspberry Pi OS 6.3** — нова версія операційної системи, вийшла 15 вересня 2026. [Джерело](https://en.wikipedia.org/wiki/Raspberry_Pi_OS)

- **arduino-pico 6.3.2** — спільнотна підтримка RP2040/RP2350 для Arduino отримала оновлення документації (15 листопада 2026). Підтримка GPIO, SPI, I²C, serial і WiFi для Pi Pico. [Джерело](https://arduino-pico.readthedocs.io/_/downloads/en/latest/pdf/)

- **Snapmaker U1 — рекордні $20,61 млн на Kickstarter** — на CES 2026 китайський виробник встановив рекорд краудфандингу для maker-машин. [Джерело](https://chinabizinsider.com/chinese-maker-hardware-shifts-from-niche-toys-to-mass-productivity-tools-at-ces-2026/)

- **HeyGears G1X — $17,6 млн у Q3 2026** — найуспішніша технологічна кампанія третього кварталу на Kickstarter; загалом maker-інструменти зібрали $44,1 млн у Q3. [Джерело](https://www.tcf.team/blog/best-tech-kickstarters-q3-2026)

- **PiZZa: Arduino-скетчі на Raspberry Pi Zero 2 W** — відкритий проект для запуску Arduino-коду безпосередньо на Pi Zero 2 W (GPIO, SPI, I²C, serial і WiFi вже підтримуються; PWM та analogRead — поки ні). [Джерело](https://blog.adafruit.com/2026/07/01/pizza-arduino-on-the-raspberry-pi-zero-2-w/)
