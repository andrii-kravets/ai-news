## Новини
- **Arduino VENTUNO Q — офіційна ціна $399** — 19 жовтня 2026 Arduino завершила вступний період і встановила роздрібну ціну $399 (передзамовлення залишились по $299). Плата орієнтована на on-device AI для мейкерів. [Tom's Hardware / Arduino](https://www.tomshardware.com/3d-printing/3d-printing-for-consumers-at-ces-2026-creality-snapmaker-atomform-and-protopasta-show-their-latest-systems)
- **Arduino придбана Qualcomm** — угода оголошена у жовтні 2025, Arduino інтегрована в екосистему Dragonwing edge-AI. UNO Q побудований на «dual-brain» архітектурі. [tuxmachines.org](https://news.tuxmachines.org/n/2026/10/20/Open_Hardware_Modding_Raspberry_Pi_Pimoroni_Arduino_and_More.shtml)
- **Raspberry Pi CM5 Programming Jig** — інструмент для прошивання ОС на Compute Module 5 без carrier board. Анонсований у серпні 2026, побудований на Raspberry Pi OS. Спрощує масове виробництво пристроїв на CM5. [HotHardware](https://hothardware.com/news/raspberry-pi-jig-tool-flash-hardware-faster)
- **Raspberry Pi — подорожчання** — з 2 листопада 2026 одна з моделей подорожчала на $80 (до $385). Вплив на DIY-проєкти та навчальні програми. [xda-developers.com](https://www.xda-developers.com/pizza-turns-your-spare-raspberry-pi-zero-w-and-2-w-into-an-arduino/)
- **PiZZa — Raspberry Pi Zero як Arduino** — відкритий проєкт перетворює Pi Zero W або Zero 2 W на Arduino-сумісну плату. Прошивається з SD-карти, скетчі завантажуються з Arduino IDE 2.x. [xda-developers.com](https://www.xda-developers.com/pizza-turns-your-spare-raspberry-pi-zero-w-and-2-w-into-an-arduino/)
- **Sixfab Hey Hi (AI) HAT+** — новий low-power AI-акселератор від Sixfab та DEEPX для Raspberry Pi 5. Розширює можливості локального AI-inference на SBC. [tuxmachines.org](https://news.tuxmachines.org/n/2026/10/20/Open_Hardware_Modding_Raspberry_Pi_Pimoroni_Arduino_and_More.shtml)
- **Openprinter** — відкритий струменевий принтер без DRM, файли під ліцензією CC BY-NC-SA 4.0. Команда з Парижа планує запуск краудфандингу на CrowdSupply восени 2026. [CrowdSupply](https://www.crowdsupply.com/open-tools/openprinter)
- **Clura — open-source корпус для 3D-принтера** — краудфандинг на Kickstarter, нагороди від $119. Файли конструкції на GitHub під Creative Commons NonCommercial. [Hackster.io](https://www.hackster.io/news/the-open-source-clura-delivers-everything-you-need-in-a-3d-printer-enclosure-and-more-fc311cc6c57e)
- **SensWear** — відкрита платформа для носимих пристроїв на базі Nordic nRF54L15 BLE SoC. Орієнтована на розробку медичних та фітнес-гаджетів з відкритим кодом. [tuxmachines.org](https://news.tuxmachines.org/n/2026/10/20/Open_Hardware_Modding_Raspberry_Pi_Pimoroni_Arduino_and_More.shtml)
