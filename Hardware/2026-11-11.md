# Hardware / DIY Electronics Дайджест 2026-11-11

## Ключові тези
- Raspberry Pi підняла ціни: 16GB Pi 5 подорожчав на $80 до $385 через зростання вартості пам'яті; одночасно в Linux-ядрі знайдено посилання на Pi Zero 3 W та Pi 4 Model A
- Adafruit Metro ESP32-P4 Hydra ($34.95, 26 жовтня 2026): ESP32-P4 + ESP32-C6 на формфакторі Arduino Uno з WiFi 6 і Raspberry Pi-сумісними MIPI-роз'ємами
- Arduino App Lab 0.11.0 для UNO Q дозволяє публікувати версіоновані Python-застосунки на мікроконтролері з Linux-ядром — новий клас Python-on-board проєктів

## Новини
- **Raspberry Pi 5 — підвищення ціни** — На початку листопада 2026 Raspberry Pi Ltd підняла ціни через зростання вартості пам'яті та компонентів: 16GB Pi 5 — $385 (+$80), 16GB Compute Module 5 — +$40. Pi 500+ ціна не змінилася. Raspberry Pi OS не оновлювався (остання версія: 2026-10-06). [MoodleBox / GitHub](https://github.com/moodlebox/moodlebox/issues/446)
- **Raspberry Pi Zero 3 W та Pi 4 Model A — витоки з ядра** — Файли device tree в Linux-ядрі вказують на два нові оголошені плати: Pi Zero 3 W і Pi 4 Model A. Офіційного анонсу від Raspberry Pi ще не було, характеристики та ціни не відомі. [Adafruit Newsletter](https://blog.adafruit.com/2026/11/03/the-python-on-microcontrollers-newsletter-adafruit-metro-p4-hydra-possible-new-raspberry-pi-boards-jit-gone-and-more)
- **Adafruit Metro ESP32-P4 Hydra ($34.95)** — Анонсована 26 жовтня 2026. Плата на формфакторі Arduino Uno з ESP32-P4 (16 MB PSRAM) + окремим ESP32-C6 для WiFi 6, Bluetooth 5.3, Thread і Zigbee. MIPI-роз'єми сумісні з Raspberry Pi Touch Display 2 і камерами OV5647. CircuitPython поки в альфа, Arduino — в розробці. [CNX Software](https://cnx-software.com/2026/10/26/adafruit-metro-esp32-p4-hydra-an-arduino-uno-shaped-esp32-p4-esp32-c6-board-with-wifi-6-mipi-interfaces)
- **Arduino App Lab 0.11.0 для UNO Q** — Оновлення додає версіоновані релізи Python-застосунків для Arduino UNO Q (ESP32-P4 із Linux-ядром). Тепер підтримуються кілька Raspberry Pi HAT прямо на UNO Q. Одна плата одночасно запускає Arduino-скетч і Python-застосунок на Linux-стороні. [Electronic Design](https://www.electronicdesign.com/technologies/embedded/product/55403971/electronic-design-5-new-raspberry-pi-hardware-releases-in-2026)
- **Adafruit Python on Microcontrollers Newsletter (3 листопада)** — Тижневий дайджест охоплює: Metro ESP32-P4 Hydra, можливі нові плати Raspberry Pi, зникнення JIT-компілятора та інші новини. Відстежує MicroPython, CircuitPython та board-релізи. [Adafruit Blog](https://blog.adafruit.com/2026/11/03/the-python-on-microcontrollers-newsletter-adafruit-metro-p4-hydra-possible-new-raspberry-pi-boards-jit-gone-and-more)
- **Kode Dot — кишеньковий ESP32-S3 maker-пристрій** — Kickstarter-кампанія зібрала $2 211 962 від 10 817 бекерів. Pocket-size пристрій на ESP32-S3 із дисплеєм та кнопками для maker-проєктів на ходу. [KickTraq](https://www.kicktraq.com/projects/kode/kode-dot-the-all-in-one-pocket-size-maker-device/)
- **Xerxes Pi 2026 — Raspberry Pi/Jetson carrier board** — Нова ітерація популярного home-lab carrier board для модулів Raspberry Pi і NVIDIA Jetson; активна краудфандингова кампанія на Crowd Supply. Успадковує успіх Xerxes Pi 2025. [Crowd Supply](https://www.crowdsupply.com/crowdfunding)
