# Hardware / DIY Electronics Дайджест 2026-09-02

## Ключові тези
- WifiSense-Pi: ESP32-S3 + Pi 4 вимірюють присутність людини через зміни Wi-Fi сигналу без будь-яких датчиків
- Gemma Translator на Pi 5 — повністю офлайновий AI-перекладач зі 60+ мовами на базі Google Gemma 4 та LiteRT
- Challenger+ RP2350 NB-IoT поєднує RP2350 з LTE Cat NB2 — перша такого роду компактна плата для IoT зв'язку

## Новини
- **WifiSense-Pi: детектор присутності без датчиків** — Відкритий проєкт WifiSense-Pi використовує ESP32-S3 (100 замірів/с у каналі 2,4 ГГц) і Raspberry Pi 4 (обробка сигналу) для виявлення людини через зміни Wi-Fi CSI (Channel State Information). Жодних PIR-датчиків — тільки існуючий Wi-Fi сигнал. Код відкрито. [Джерело](https://www.opensourceforu.com/2026/08/esp32-and-raspberry-pi-build-detects-human-presence/)

- **Gemma Translator: офлайновий AI-перекладач на Pi 5** — Відкритий проєкт Gemma Translator запускає Google Gemma 4 через LiteRT runtime прямо на Raspberry Pi 5 і виконує багатомовний переклад (60+ мов) повністю локально без хмарних API. Ідеально для кіосків, вбудованих перекладачів і privacy-чутливих застосунків. [Джерело](https://news.tuxmachines.org/n/2026/08/10/Linux_Devices_and_Open_Hardware_Modding_Raspberry_Pi_ESP32_and_.shtml)

- **Challenger+ RP2350 NB-IoT: клітинний зв'язок для IoT** — ILABS випустила Challenger+ RP2350 NB-IoT — компактну плату, що поєднує двоядерний RP2350 (Raspberry Pi) з модулем STMicroelectronics ST87M01-1301 LTE Cat NB2. Орієнтована на ultra-low-power IoT-вузли з потребою у широкозоновому зв'язку, де Wi-Fi недоступний. [Джерело](https://news.tuxmachines.org/n/2026/08/10/Linux_Devices_and_Open_Hardware_Modding_Raspberry_Pi_ESP32_and_.shtml)

- **Raspberry Pi CM5 Programming Jig — інструмент масового розгортання** — У серпні 2026 вийшов офіційний Programming Jig для Compute Module 5: спеціалізований пристрій для програмування CM5-плат з вашою операційною системою та конфігурацією безпеки. Спрощує серійне виробництво та deployment. [Джерело](https://www.phoronix.com/news/Raspberry-Pi-CM5-Jig)

- **CM5-based міні-ПК для локального OpenClaw AI** — Новий міні-ПК на базі Raspberry Pi Compute Module 5 орієнтований на локальний запуск OpenClaw — AI-фреймворку для edge inference. Проєкт демонструє, як CM5 стає платформою не лише для IoT, а й для серйозних edge AI завдань. [Джерело](https://news.tuxmachines.org/n/2026/08/17/Raspberry_Pi_CM5_based_mini_PC_targets_local_OpenClaw_deploymen.shtml)

- **Make: Guide to Boards 2026 (Volume 95)** — Makezine видав повний довідник плат для мейкерів 2026 року з порівнянням Arduino UNO Q, Pi 5, ESP32-серії та нових RISC-V плат. Виданий у форматі «No Computer Required» — орієнтований на проєкти, що не потребують повноцінного ПК. [Джерело](https://makezine.com/volume/make-volume-95-guide-to-boards-2026/)

- **Raspberry Pi у 2026: масштабована платформа для AI-мейкерів** — Аналіз середини 2026 показує: Raspberry Pi утримує баланс між масштабованістю (CM5 у промисловому IoT) і мейкерськими коренями. Найпопулярніший проєкт 2026 — локальний AI з Ollama на Pi 5 (8 ГБ): ретро-ігри на PS2/GameCube, Minecraft-сервер і, особливо, приватний LLM-асистент. [Джерело](https://www.tech-reader.blog/2026/07/the-raspberry-pi-in-2026-scalable.html)
