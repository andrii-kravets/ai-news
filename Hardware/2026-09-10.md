# Hardware / DIY Electronics Дайджест 2026-09-10

## Новини
- **Olimex ESP32-P4-PC: open-source SBC з HDMI** — болгарська компанія Olimex представила нову плату на базі dual-core RISC-V ESP32-P4: 768 KB внутрішньої RAM + 32 MB PSRAM, нативний Ethernet, USB-JTAG, CSI-камера, MIPI DSI-дисплей та HDMI-вихід. Схеми і KiCad-файли у відкритому доступі. [Adafruit Blog — Olimex ESP32-P4-PC](https://blog.adafruit.com/2026/02/18/the-new-esp32-p4-pc-open-source-hardware-board/)

- **TickrCast: ESP32-S3 HUB75 LED-дисплей** — Layered Ventures LLC запустила TickrCast — розширювальний LED-тікер на ESP32-S3. Відображає live-дані esports, спортивних рахунків, соцмедіа-метрик та відстеження рейсів через daisy-chain конфігурацію. Перший споживчий продукт у ніші HUB75-дисплеїв. [Tux Machines — Open Hardware Sept 4 2026](https://news.tuxmachines.org/n/2026/09/04/Open_Hardware_Modding_Linux_ESP32_Arduino_Zephyr_and_More.shtml)

- **Open RC Spotter: ESP32-платформа для RC-гонок** — відкрита апаратна платформа для високопродуктивних RC-автомобілів на базі ESP32. Зчитує IMU, GPS, температуру, батарею та IR-маяки для lap timing; генерує відфільтрований потік даних із позицією, швидкістю та таймінгами кіл. [Tux Machines — Open Hardware Sept 4 2026](https://news.tuxmachines.org/n/2026/09/04/Open_Hardware_Modding_Linux_ESP32_Arduino_Zephyr_and_More.shtml)

- **Arduino + Zephyr RTOS: нова інтеграція** — Tux Machines від 4 вересня 2026 фіксує активний розвиток інтеграції Arduino з Zephyr RTOS — фреймворком для embedded із підтримкою широкого спектру чипів поза традиційною Arduino-екосистемою. Розширює Arduino на industrial IoT. [Tux Machines — Sept 4](https://news.tuxmachines.org/n/2026/09/04/Open_Hardware_Modding_Linux_ESP32_Arduino_Zephyr_and_More.shtml)

- **Grml 2026.09: Linux дистрибутив для сисадмінів** — вийшов Grml 2026.09 на ядрі Linux 7.1 із всіма оновленнями пакетів та патчами безпеки з Debian Testing станом на вересень 2026. Спеціалізований rescue/live-дистрибутив для системних адміністраторів та maker-середовищ. [Tux Machines — Sept 4](https://news.tuxmachines.org/n/2026/09/04/Open_Hardware_Modding_Linux_ESP32_Arduino_Zephyr_and_More.shtml)

- **Ubuntu 26.10 "Stonking Stingray" у розробці** — розробка Ubuntu 26.10 стартувала 30 квітня 2026 на ядрі Linux 7.0 та GNOME 50. Для maker-ком'юніті це означає оновлений стек для SBC і DIY-серверів із підтримкою новітнього hardware. [Tux Machines — Sept 4](https://news.tuxmachines.org/n/2026/09/04/Open_Hardware_Modding_Linux_ESP32_Arduino_Zephyr_and_More.shtml)

- **Bambu Lab MakerWorld: краудфандинг для 3D-дизайнерів** — Bambu Lab запустила на своїй платформі MakerWorld інструмент краудфандингу, що дозволяє ком'юніті фінансувати дизайнерів великих і складних 3D-проектів. Нова модель монетизації для open-source hardware-дизайнерів всередині екосистеми Bambu.
