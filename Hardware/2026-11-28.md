## Новини
- **Tessera — open-source дашборд для Home Assistant (23 листопада 2026)** — Запущено проект дашборду, що працює на дешевих ESP32 touchscreen-платах (2.8"–10.1"). Ліцензія GNU AGPL v3; підтримка Guition 10.1" ще в тестуванні. Дозволяє зібрати домашню панель управління за $20–50 замість комерційних аналогів. [CNX Software](https://www.cnx-software.com/2026/11/23/tessera-open-source-dashboard-for-home-assistant-runs-on-esp32-touchscreen-devkits/)
- **Syndetis — ESP32-аналізатор Ethernet (листопад 2026)** — Портативний пристрій на базі WT32-ETH01 з OLED-екраном: перевіряє підключення, DHCP, дублювання IP і дані комутатора без ноутбука. MIT-ліцензія, відкритий проект. Ніша: польова діагностика мережі для мейкерів і сисадмінів. [Open Source For You](https://www.opensourceforu.com/2026/11/open-source-esp32-tool-checks-ethernet-connections/)
- **CyberCore status panel та KOTH-Timer (Tindie, листопад 2026)** — Два відкритих апаратних проекти з KiCad-файлами (CERN-OHL-S-2.0) і MIT-прошивкою, доступні на Tindie. CyberCore — панель стану з RGB-підсвіткою, KOTH-Timer — таймер для змагань у стилі «King of the Hill». [Tindie Blog](https://blog.tindie.com/2026/11/open-hardware-files-an-esp32-s3-status-panel-and-a-match-timer/)
- **ESP32-S3 камера для Prusa Connect (листопад 2026)** — Прошивка під GPL-3.0, що перетворює ESP32-S3 на камеру для моніторингу 3D-друку через Prusa Connect. Перегляд прогресу друку у реальному часі без зовнішнього Raspberry Pi. [Open Source For You](https://www.opensourceforu.com/2026/11/open-source-firmware-turns-esp32-s3-into-a-3d-camera/)
- **Flipper One — відкрито pre-замовлення (початок листопада 2026)** — Successor Flipper Zero. Купон $20 дає право придбати одиницю за $379 на Kickstarter (дата кампанії ще не оголошена). Апаратна специфікація не розкрита; проект залежить від кількості попередніх замовлень для запуску виробництва. [Hardware News Weekly](https://note.com/jiur/n/n545e8eac0d05?hl=en)
- **Dreaming Robots EEW Maker Kit — Kickstarter (листопад 2026)** — Набір для раннього попередження про землетруси запустив кампанію на Kickstarter. Стандартний пакет — $99. Орієнтований на мейкерів, що хочуть власну сейсмічну станцію вдома. [Dreaming Robots Blog](https://www.dreamingrobots.com/blog/)
- **Tindie AI Hardware Creative Challenge (1 листопада 2026 — 31 січня 2027)** — Tindie оголосив конкурс для AI-hardware проектів із призовим фондом $2 500. Мета: стимулювати мейкерів створювати working AI hardware (не симуляції). [Tindie](https://www.tindie.com/campaigns/ai-hardware-2026/)
