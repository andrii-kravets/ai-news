## Новини

- **Creality K3 — многоколірний флагман за $849 (з 12 жовтня)** — Prusa-style 4-насадкова система для мультиколірного друку. Замовлення відкриті 12 жовтня — 30 листопада 2026; покупці отримують 4 котушки Hyper PLA безкоштовно. Конкурент Bambu Lab AMS у нижчому ціновому сегменті. [Посилання](https://3dprint.com/334925/creality-k3-opens-for-pre-order-at-849-advancing-multi-color-3d-printing/)

- **Bambu Lab S1 — 3D-сканер, листопад 2026** — Bambu Lab підтвердила запуск S1 handheld 3D-сканера у листопаді. Перший сканер у лінійці; розрахований на інтеграцію з принтерами X-серії для замикання циклу дизайн–сканування–друк. [Посилання](https://3dprint.com/334771/3d-printing-news-briefs-10-14-2026/)

- **UniFormation S10 — принтер+мийка+сушка в одному** — Новий desktop resin-принтер, що поєднує друк, постобробку (мийку ізопропанолом) і UV-сушку в єдиному корпусі. Усуває необхідність у окремих станціях — популярний формат у жовтневих оглядах. [Посилання](https://3dprint.com/334771/3d-printing-news-briefs-10-14-2026/)

- **InfiMaker K1 — 5-осьовий CNC, $4.29 млн на Kickstarter** — Desktop 5-axis CNC-фрезер для maker-спільноти зібрав $4.29 млн. Найбільший результат серед maker hardware кампаній жовтня. Застереження: у кампанії відсутня CE/FCC-сертифікація, важлива для покупців у регульованих ринках. [Посилання](https://www.crowdsupply.com/)

- **Scrap Labs — desktop металевий 3D-принтер** — Стартап виводить на ринок настільний принтер для металу: компактний і доступніший формат традиційно громіздкої технології. Деталі ціни і дати запуску поки не оголошено. [Посилання](https://www.fabbaloo.com/)

- **Raspberry Pi Smart Display Module для CM5 — $30** — Офіційний адаптер для підключення дисплея до Compute Module 5; ціна $30. Разом з ним оголошено версію Raspberry Pi Desktop (PC/Mac) на базі Debian Trixie — для розробників, які хочуть RPi-середовище на звичайному комп'ютері. [Посилання](https://news.tuxmachines.org/n/2026/10/07/Open_Hardware_Modding_Raspberry_Pi_Arduino_and_More.shtml)

- **Arduino-Pico 6.3.0 — підтримка RP2350 (13 жовтня)** — Реліз Earle Philhower від 13 жовтня 2026: оновлений core для RP2040 та новий Raspberry Pi RP2350. Дозволяє використовувати Arduino IDE з платами Pi Pico 2 та Pico 2W. [Посилання](https://arduino-pico.readthedocs.io/_/downloads/en/latest/pdf/)

- **ESP32 Bit Pirate — open-source інструмент апаратного хакінгу** — $8 ESP32-S3-плата перетворюється на багатопротокольний аналізатор (SPI, I2C, UART, JTAG). Проєкт опублікований на початку вересня 2026, набирає популярність у спільноті security-дослідників. [Посилання](https://www.libhunt.com/topic/esp32)
