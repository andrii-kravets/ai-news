- **SCINTIX P4: ESP32-P4 RISC-V Compute Module для CM4-carrier** — SCINTIX P4 — новий compute module на базі ESP32-P4 RISC-V із модулем ESP32-C6 для бездротового зв'язку, сумісний із Raspberry Pi CM4/CM5 carrier boards. Дозволяє перевикористовувати існуючу CM4 інфраструктуру з ESP32-P4. Перспективний для edge AI і промислового IoT. [Tux Machines — Open Hardware Aug 2026](https://news.tuxmachines.org/n/2026/08/15/Open_Hardware_Modding_Raspberry_Pi_5_ESP32_and_More.shtml)

- **Apollo Automation ESPHome Starter Kit: smart home без паяння** — Apollo Automation випустила ESPHome Starter Kit — модульну платформу на базі ESP32-C6 для створення ESPHome-пристроїв без паяння, breadboard-ів або написання коду. Пристрій працює локально і може інтегруватися з Home Assistant. Перший споживчий no-code ESP32-kit для DIY-домашньої автоматизації. [Tux Machines — Open Hardware Aug 2026](https://news.tuxmachines.org/n/2026/08/15/Open_Hardware_Modding_Raspberry_Pi_5_ESP32_and_More.shtml)

- **Velxio: браузерний симулятор Arduino, ESP32 і Raspberry Pi** — Velxio — open-source, self-hosted симулятор, що дозволяє drag-and-drop плати, підключати компоненти, писати та запускати Arduino/Python-код і переглядати серійну консоль прямо у браузері — без реального заліза. Ідеально для навчання та прототипування без інвестицій у hardware.
