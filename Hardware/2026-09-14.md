# Hardware / DIY Electronics Дайджест 2026-09-14

## Новини
- **Arduino Ventuno Q: Linux + 40 TOPS NPU за $299** — Embedded World 2026 (березень) Arrow Electronics та Arduino представили Ventuno Q — SBC на базі Qualcomm Dragonwing IQ-8 SoC (8-ядерний Kryo Gen 6, Adreno 623 GPU) із 16 GB LPDDR5 RAM, 64 GB eMMC і NPU до 40 TOPS. Паралельно — STM32H5 мікроконтролер для низько-латентного управління моторами. Ціна: менше $300, доступний з Q2 2026. Перша SBC від Qualcomm-Arduino-ери, де class Linux-сервера й класичний maker-форм-фактор поєднані в одному пристрої. [CNX Software — Arduino Ventuno Q](https://www.cnx-software.com/2026/08/25/299-arduino-ventuno-q-sbc-combines-qualcomm-dragonwing-iq8-soc-and-stm32h5-mcu/)

- **Raspberry Pi 500+: механічна клавіатура + NVMe за $200** — Raspberry Pi анонсувала 500+ — оновлений "комп'ютер у клавіатурі": процесор BCM2712 (той самий, що в Pi 5), 16 GB RAM, вбудований M.2-слот із попередньо встановленим 256 GB SSD Raspberry Pi, механічна клавіатура з RGB LED та знімними ключами, Wi-Fi 6, BT 5.2, два micro-HDMI для двох 4K-моніторів. Перша моделей Pi 500 серії з NVMe — нарешті plug-and-play desktop для maker-аудиторії без зовнішньої периферії. [Raspberry Pi — 500+ On Sale](https://www.raspberrypi.com/news/the-ultimate-all-in-one-pc-raspberry-pi-500-plus-on-sale-now-at-200/)

- **M5Stack PaperMono і PaperMono-Lite: ESP32-S3 e-paper для IoT** — M5Stack випустила два нових компактних девборди на базі ESP32-S3 із 3,97-дюймовим grayscale сенсорним e-paper дисплеєм. PaperMono — повна версія зі всіма роз'ємами, PaperMono-Lite — полегшений варіант. Орієнтовані на IoT-пристрої з тривалою батарейною роботою, де потрібне оновлення інформації без підсвітки (ціновики, датчики, домашні панелі). [Tux Machines — Open Hardware Aug 2026](https://news.tuxmachines.org/n/2026/08/22/Open_Hardware_Modding_ESP32_GrapheneOS_and_More.shtml)

- **TickrCast: ESP32-S3 HUB75 LED-тікер для геймерів і трейдерів** — Layered Ventures LLC запустила TickrCast — розширювану HUB75 LED-панель на ESP32-S3. Готовий споживчий продукт відображає live esports-результати, спортивні рахунки, метрики соцмереж і відстеження авіарейсів у daisy-chain конфігурації. Перехід ESP32-S3 з DIY-ніші в готові consumer-продукти. [IoT Beat — Top ESP32 IoT Projects 2026](https://iotbeat.com/blog/top-10-esp32-iot-projects-you-can-build-in-2026)

Огляд охоплює весь спектр від nano-мікроконтролерів до full Linux SBC — корисна карта для вибору платформи на майбутні проєкти. [Makezine — Guide to Boards 2026](https://makezine.com/article/technology/arduino/guide-to-boards-2026-super-tiny-computers/)
