- **Raspberry Pi AI HAT+ 2: локальний ШІ для Pi 5** — Новий апаратний модуль додає прискорення генеративного ШІ та комп'ютерного зору безпосередньо до Raspberry Pi 5 без хмарних залежностей. Входить до топ-5 релізів Pi у 2026 році. [Посилання](https://www.electronicdesign.com/technologies/embedded/product/55403971/electronic-design-5-new-raspberry-pi-hardware-releases-in-2026)
- **Raspberry Pi Compute Module 5: для вбудованих систем** — CM5 пакує потужність Pi 5 у компактну плату для роботики, промислового обладнання та кіосків. На Embedded World демонструвався стенд для масового програмування CM5. [Посилання](https://www.electronicdesign.com/technologies/embedded/product/55403971/electronic-design-5-new-raspberry-pi-hardware-releases-in-2026)
- **Pi 500+ та Raspberry Pi OS 6.3** — Найновіший настільний комп'ютер від Pi вийшов за два тижні до офіційного Handbook 2026. Остання версія ОС — Pi OS 6.3 від 15 вересня 2026. [Посилання](https://www.raspberrypi.com/news/the-official-raspberry-pi-handbook-2026-is-here/)
- **Arduino VENTUNO Q на Embedded World 2026** — Arduino показала нову плату VENTUNO Q з фокусом на ШІ та роботику. Паралельно: Qualcomm підтвердив придбання Arduino та Edge Impulse, що ставить питання про майбутню відкритість екосистеми. [Посилання](https://www.elektormagazine.com/news/embedded-world-2026-day-1)
- **Bambu Lab X2D: флагман з подвійною екструзією за $649** — Новий принтер X2D з подвійною екструзією позиціонується для тих, хто хоче творити, а не налагоджувати техніку. Ціна — від $649. [Посилання](https://ohsem.me/?p=196554)
- **Clura: відкритий корпус для 3D-принтера від TU Delft** — Студенти Делфтського університету створили повністю відкритий корпус для принтера з HEPA/вугільною фільтрацією та датчиками якості повітря. Проєкт відтворюється на звичайному FDM-принтері. [Посилання](https://3dprint.com/325609/3d-printing-news-briefs-4-25-2026/)

Прошивка та слайсер залишаються відкритими, хоча файли апаратного дизайну не публікуються.
