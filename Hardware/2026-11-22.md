# Hardware / DIY Electronics Дайджест 2026-11-22

## Ключові тези
- Circuit Digest: 6-екранний LED-куб на Raspberry Pi CM4 з реакцією на музику (20 листопада)
- Maker.pro та AllAboutCircuits публікують хвилю ESP32/Arduino-проектів за третій тиждень листопада

## Новини
- **6-екранний LED-куб на Pi CM4 (Circuit Digest, 20 листопада)** — Maker-проект: куб з шести LED-панелей, керований Raspberry Pi Compute Module 4, реагує на музику в реальному часі. Технічна складність: синхронізація 6 матриць через CM4 з мінімальною затримкою. [Circuit Digest](https://circuitdigest.com)
- **ESP32-based DSP audio effect (Maker.pro, 17 листопада)** — Проект на ESP32 реалізує DSP-ефекти для аудіо в реальному часі: реверб, дистошн, еквалайзер. Всі обчислення — на мікроконтролері без зовнішнього процесора. [Maker.pro](https://maker.pro/projects)
- **Closed-loop brushless motor adapter (AllAboutCircuits, 18 листопада)** — Плата для перетворення звичайного brushless-мотора на мотор зі зворотним зв'язком за положенням. Актуально для 3D-принтерів та ЧПУ-верстатів. [All About Circuits](https://www.allaboutcircuits.com/projects/)
- **Touchscreen calculator: Arduino + ILI9486 TFT (Engineers Garage, 9 листопада)** — Покроковий проект: калькулятор з кольоровим сенсорним екраном. Гарний старт для освоєння TFT-дисплеїв з Arduino. [Engineers Garage](https://www.engineersgarage.com/projects-and-tutorials/)
- **EFY листопад 2026: GPS smart air compressor + Li-Fi Morse** — Листопадовий номер Electronics For You містить GPS-компресор з автоматичним управлінням тиском і Li-Fi проект передачі Morse-коду через ліхтарик. Класичний hobbyist DIY стиль. [Electronics For You](https://www.electronicsforu.com/special/november-2026-issue-of-electronics-for-you)
- **Romu: мінімалістична RP2354A USB-плата (краудфандинг до 26 листопада)** — Bitmerse відкрив краудфандинг 13 жовтня 2026, мета $5 000. Плата на базі RP2354A з MicroPython, компактна USB-форм-фактор для DIY та IoT. Кампанія завершується 26 листопада. [esp32.co.uk](https://esp32.co.uk/?p=20261011220)
- **ESP32 Agent Dev Kit** — ESP32-S3 голосовий асистент з підтримкою ChatGPT, Claude та Gemini через платформу Coze AI. Краудфандинговий проект, що демонструє тренд: LLM безпосередньо на мікроконтролері. [Hackster.io](https://cnx-software.com/?p=144346)
