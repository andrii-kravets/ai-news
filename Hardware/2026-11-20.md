[Tom's Hardware](https://www.tomshardware.com/3d-printing/3d-printing-for-consumers-at-ces-2026-creality-snapmaker-atomform-and-protopasta-show-their-latest-systems)

- **Makera Z1 — настільний ЧПУ-верстат** — зібрав $10,25 млн на краудфандингу; автоматична зміна інструментів, авторівнювання та однокнопкове калібрування знижують бар'єр для DIY-майстрів. [Tom's Hardware](https://www.tomshardware.com/3d-printing/3d-printing-for-consumers-at-ces-2026-creality-snapmaker-atomform-and-protopasta-show-their-latest-systems)

- **Arduino UNO Q ($44)** — нова плата від Arduino (яку придбала Qualcomm) об'єднує чотириядерний Arm Cortex-A53 з Linux і Arm Cortex-M33 для мікроконтролерних завдань; підтримує Python, MicroPython та C++. [Make:](https://makezine.com/article/technology/arduino/guide-to-boards-2026-super-tiny-computers/)

- **Raspberry Pi 500+ ($200)** — клавіатурний комп'ютер з 256 ГБ NVMe SSD та передвстановленою Raspberry Pi OS; перша масова модель RPi «з коробки» без додаткових аксесуарів. [Make:](https://makezine.com/article/technology/guide-to-boards-2026-no-computer-required/)

- **PiZZa: Arduino-скетчі на Raspberry Pi Zero 2 W** — open-source community-проєкт, що дозволяє запускати Arduino-код безпосередньо на RPi Zero 2 W (обмеження: PWM/analogWrite поки не підтримуються). [Adafruit Blog](https://blog.adafruit.com/2026/07/01/pizza-arduino-on-the-raspberry-pi-zero-2-w/)

- **Silicon Labs Simplicity AI SDK — публічна бета** — SDK для вбудованих систем вийшов у публічну бету 7 жовтня 2026 з підтримкою GitHub Copilot, Cursor та Codex; спрощує написання прошивок через ШІ-асистентів. [AllSpice](https://allspice.io/post/12-of-the-best-ai-tools-for-hardware-and-electrical-engineers-in-2026)

- **Quilter — ШІ для розводки PCB** — інструмент приймає схему з Altium/KiCad, параметри плати та правила DRC і повертає кілька варіантів розводки в нативному форматі; зменшує час ручного трасування. [Quilter.ai](https://www.quilter.ai/blog/the-next-wave-of-innovation-in-hardware-design-for-2026-and-beyond)
