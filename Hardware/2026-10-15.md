# Hardware / DIY Electronics Дайджест 2026-10-15

## Ключові тези
- LILYGO T-Dongle-C5 та Espressif ESP-Mosaico — нові ESP32-платформи з WiFi 6 та розширюваним дизайном
- GlitchCaster — open-hardware EMFI-інструмент для безпекових досліджень на основі 3D-принтера
- Raspberry Pi CM5 Jig автоматизує промислове програмування модулів; Raspberry Pi OS 6.3 вийшов у вересні

## Новини
- **LILYGO T-Dongle-C5 — ESP32-C5 USB-донгл** — Новий компактний донгл на ESP32-C5 з подвійним WiFi 6 (2.4/5 ГГц), BLE та 802.15.4; розвиває лінійку T-Dongle-S3. Ідеальний для IoT-прототипів. [Посилання](https://news.tuxmachines.org/n/2026/10/07/Open_Hardware_Modding_Raspberry_Pi_Arduino_and_More.shtml)

- **Espressif ESP-Mosaico — розширюваний dev kit** — Smart-interaction kit на ESP32-S3 із модульною архітектурою для голосового та жестового інтерфейсу. [Посилання](https://news.tuxmachines.org/n/2026/09/27/Open_Hardware_Modding_Reverse_engineering_ESP32_and_More.shtml)

- **GlitchCaster — open-hardware EMFI-інструмент** — Інструмент для fault-injection досліджень, що використовує голівку 3D-принтера для точного позиціонування та генерує 250 В ЕМ-імпульси. Опублікований ~10 жовтня 2026. [Посилання](https://www.open-electronics.org/)

- **Raspberry Pi CM5 Programming Jig** — Офіційний jig для автоматизованого програмування Compute Module 5: secure boot, повне шифрування диска, встановлення ОС. Єдина альтернатива (Everypin) коштує ~$2500. [Посилання](https://hothardware.com/news/raspberry-pi-jig-tool-flash-hardware-faster)

- **Raspberry Pi OS 6.3 — вийшов 15 вересня 2026** — Черговий стабільний реліз ОС для одноплатних комп'ютерів Raspberry Pi. [Посилання](https://en.wikipedia.org/wiki/Raspberry_Pi_OS)

- **ESP32 + термопринтер — 4 DIY-проєкти вихідного дня** — HowToGeek опублікував добірку з 4 творчих проєктів на базі ESP32 та термопринтера для тих, хто шукає ідеї (2–4 жовтня 2026). [Посилання](https://www.howtogeek.com/fun-esp32-thermal-printer-projects-make-this-weekend-oct-2-4/)

- **Adafruit Fruit Jam — мультисередовищна плата** — Підтримує CircuitPython, Arduino і Pico SDK в одному пристрої; анонсована на початку 2026, набирає популярність у maker-спільноті. [Посилання](https://blog.adafruit.com/categories/raspberry-pi/)
