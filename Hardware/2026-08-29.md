- 2026 — рік toolchanger 3D-принтерів: Prusa XL+, Creality K3 (KliTek), Sovol M1D та ProForge 5 — відразу чотири конкуруючих рішення на ринку

## Новини

- **Prusa XL+ починає відвантажуватися (28 серпня 2026)** — Prusa запустив постачання оновленого флагмана: єдиний UX, швидший друк, краща якість поверхні, hardware-апдейти. До 5 голівок із блискавичним механізмом зміни. На сьогодні XL+ залишається найбільшим та найфункціональнішим toolchanger-принтером на масовому ринку. [Prusa Blog](https://blog.prusa3d.com/xl-in-2026-new-toolheads-lower-price_129707/)

- **Creality K3 — наступний флагман із власним KliTek toolchanging** — Creality анонсувала K3 із новою системою заміни голівок KliTek. Реліз очікується до кінця 2026. Creality офіційно входить у гонку toolchanger-принтерів, де раніше домінував Prusa XL. [All3DP](https://all3dp.com/4/crealitys-next-generation-of-3d-printer-to-be-a-klitek-powered-toolchanger/)

- **Sovol M1D — IDEX та toolchanger в одному (Kickstarter, від $1 499)** — Sovol готує M1D: поєднує переваги IDEX-архітектури (copy, mirror режими) з гнучкістю toolchanger для довільного підбору матеріалів. Старт краудфандингу на Kickstarter, базова ціна від $1 499. [All3DP](https://all3dp.com/4/sovol-is-bringing-idex-back-with-its-upcoming-m1d-toolchanger-3d-printer/)

- **ProForge 5 — open-source 5-голівковий toolchanger на Kickstarter (500×400×500 мм)** — Makertech 3D збирає кошти на ProForge 5: відкрита архітектура, 5 незалежних голівок, великий об'єм друку 500×400×500 мм. Орієнтований на мейкерів і малі виробництва з потребою в мультиматеріальному друку. [Kickstarter](https://www.kickstarter.com/projects/proforge-3d-printer/proforge5)

- **Makita серпень 2026: 4 нових інструменти 18V LXT та 40V max XGT** — Makita додала 4 нових кордлес-інструменти: 40V max XGT Brushless Backpack Blower (еквівалент бензинового 65 куб. см; 675 CFM, 215 mph), 18V LXT Positive Placement Metal Connector Nailer (для джойст-ханґерів із точним попаданням у перфорований отвір). Рішення для будівельного та outdoor-ринку. [Spreely News](https://news.spreely.com/makita-adds-four-new-tools-for-august-2026/)

- **openbricks: MicroPython firmware для ESP32-S3 роботів із MuJoCo-симулятором (18 серпня 2026)** — Відкритий (MIT) проєкт openbricks реалізує Pybricks-стиль Python robotics API для ESP32-S3: $15 serial-bus servo, SPI IMU, reflectance array. Код компілюється на хості через mpy-cross і завантажується через BLE. MuJoCo-симулятор запускає той самий firmware API без фізичного заліза — зручно для розробки та тестування. [Adafruit Blog](https://blog.adafruit.com/2026/08/18/icymi-python-on-microcontrollers-newsletter-openbricks-your-esp32-robot-circuitpython-day-python-guitar-pedal-and-more)

- **OomWoo — open-source робот-пилосос власноруч за ~$200 (ESP32 + Raspberry Pi 5)** — OomWoo — повністю відкритий DIY-проєкт: ESP32 як контролер руху, Raspberry Pi 5 (4 ГБ) для обробки зображень та логіки. Кошторис деталей ~$200 + вартість RPi5. За функціональністю відповідає комерційним моделям у класі $600: підтримка moping, obstacle detection преміум-рівня. [Adafruit Blog](https://blog.adafruit.com/2026/08/18/icymi-python-on-microcontrollers-newsletter-openbricks-your-esp32-robot-circuitpython-day-python-guitar-pedal-and-more)
