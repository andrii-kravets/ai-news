# Продуктивність / PKM Дайджест 2026-08-24

## Ключові тези
- Capacities Release 68 (серпень 2026) приніс оновлений мобільний застосунок, нові AI-чати і аналіз вебпосилань для Pro
- Zettlr 4.6.0 вийшов 13 червня 2026 — найбільша серія оновлень після мажорного релізу 4.0 у грудні 2025
- Tana офіційно розділила продукт на «Tana New» (enterprise meeting intelligence, конкурент Notion) і «Tana Old» (outliner)

## Новини
- **Capacities Release 68 — мобільний редизайн і AI-чати** — У серпні 2026 Capacities випустила Release 68: повністю перероблений мобільний застосунок, виокремлений простір для AI-чатів, аналіз вебпосилань у Pro-плані, медіа в API та MCP, а також посилений AI-асистент. Це найамбітніше оновлення для мобільної аудиторії за весь час. [Посилання](https://capacities.io/whats-new)

- **Capacities Release 67 — інструменти для розробників і ридер-режим** — Release 67 (липень 2026) відкрив API і MCP для розробників, додав аналіз вебпосилань, ридер-режим, анотації та режим презентацій — Capacities поступово переростає з PKM-застосунку на платформу. [Посилання](https://capacities.io/whats-new)

- **Zettlr 4.6.0 — стабільний розвиток після мажорного релізу** — 13 червня 2026 Zettlr випустив версію 4.6.0 із численними виправленнями і покращеннями. Після мажорного релізу 4.0 (таблиці, PDF-переглядач, покращений парсер цитат) у грудні 2025 оновлення виходять регулярно — уже вийшли версії 4.1–4.6. [Посилання](https://zettlr.com/post/zettlr-460-released)

- **Storyflow — AI second brain для візуальних і творчих проєктів** — Storyflow позиціонується як найпотужніший AI second brain для creative work: побудований навколо canvas-першого підходу, де AI бачить весь контекст дошки й тактичні методики. Орієнтований на дизайнерів, письменників і командні проєкти. [Посилання](https://storyflow.so/blog/best-ai-second-brain-apps-2026)

- **Taskade Genesis — живий дашборд знань за 60 секунд** — Taskade Genesis дозволяє клонувати «живий дашборд знань» за 60 секунд: нотатки автоматично тегуються, зв'язуються і стають доступними через 7 режимів відображення. AI-асистент EVE нагадує про контекст між зустрічами і задачами. [Посилання](https://www.taskade.com/blog/ai-second-brain-tools)

- **Tana роздвоїлась: «Tana New» vs «Tana Old»** — На початку 2026 Tana офіційно розділила продукт: «Tana New» — конкурент Notion для enterprise-команд із зустрічами та структурованою пам'яттю; «Tana Old» — класичний outliner для індивідуальних PKM-практиків. Обидва напрямки розвиваються паралельно. [Посилання](https://www.saasworthy.com/compare/tana-vs-notion-so)

- **Kin Health і ClinicFrame — AI-нотатники для медицини** — Серед нових нішевих запусків 2026 року виділяються Kin Health і ClinicFrame — AI-асистенти для медичних нотаток, що адаптують шаблони та пропонуй клінічні формати. Галузева спеціалізація стала новим трендом після загального буму AI-нотатників. [Посилання](https://www.meetjamie.ai/blog/ai-note-taker)
