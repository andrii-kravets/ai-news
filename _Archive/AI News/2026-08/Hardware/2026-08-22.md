# Hardware / DIY Electronics Дайджест 2026-08-22

- ArduinoCore-zephyr v0.90.0 виходить із бети: Zephyr RTOS для Arduino офіційно стабільний

## Новини
- **ESP32-S31 у серійному виробництві** — 27 липня 2026 Espressif оголосив, що ESP32-S31 перейшов у масове виробництво і доступний для замовлення. Новий чіп розширює лінійку S3 з підвищеною продуктивністю для AI-застосунків і BLE-з'єднань. [Посилання](https://blog.adafruit.com/2026/07/27/esp32-s31-now-in-mass-production-and-available-for-purchase/)

- **RootBoard — кишеньковий Linux-термінал на Kickstarter** — Відкритий hardware-проєкт RootBoard запустився на Kickstarter 1 липня 2026. Пристрій у форм-факторі cyberdeck перетворює одноплатники на портативний Linux-PC: 3,5-дюймовий кольоровий дисплей, QWERTY-клавіатура на 70 клавіш, вбудована батарея і схема управління живленням. Ціна — від $115. [Посилання](https://www.opensourceforu.com/2026/07/open-hardware-rootboard-handheld-launched-on-kickstarter/)

- **PiZZa: Arduino-скетчі на Raspberry Pi Zero 2 W** — Розробник jetpax опублікував на GitHub інструмент PiZZa, що дозволяє писати скетчі в Arduino IDE і запускати їх безпосередньо на Raspberry Pi Zero 2 W або Zero W — без окремого мікроконтролера. [Посилання](https://blog.adafruit.com/2026/07/01/pizza-arduino-on-the-raspberry-pi-zero-2-w/)

- **Raspberry Pi Touch Display 2: нова версія на 10 дюймів** — Raspberry Pi представила 10-дюймову версію Touch Display 2, розширивши офіційну лінійку дисплеїв, яка раніше включала лише 5- і 7-дюймові моделі. Це найбільший офіційний сенсорний дисплей для Pi. [Посилання](https://news.tuxmachines.org/n/2026/07/21/Open_Hardware_Modding_Arduino_ESP32_and_More.shtml)

- **ArduinoCore-zephyr v0.90.0 — стабільний реліз** — Версія v0.90.0 ядра ArduinoCore-zephyr позначила вихід із бета-фази: інтеграція Zephyr RTOS для Arduino-плат офіційно визнана стабільною для виробничого використання. [Посилання](https://blog.adafruit.com/2026/04/07/icymi-python-on-microcontrollers-newsletter-micropython-v1-28-0-imminent-arduino-report-memory-prices-and-more)

- **Adafruit Weekly Round-Up (2 серпня): Jimothy і ESP32-S31** — Щотижневий огляд Adafruit виділив ESP32-S31 та DIY-персонаж Jimothy як ключові теми тижня. Jimothy — інтерактивний анімований персонаж на базі ESP32, що набрав популярність у maker-спільноті за незвичний підхід до HID-проєктування. [Посилання](https://blog.adafruit.com/2026/08/02/adafruit-weekly-editorial-round-up-esp32-s31-now-in-mass-production-jimothy-more/)

- **Make: Guide to Boards 2026 — розробка без ПК** — Make: Magazine опублікував оновлений гід по одноплатних комп'ютерах і мікроконтролерах. Видання 2026 підкреслює, що сучасні плати та хмарні IDE не потребують десктопного ПК для розробки — browser-based оточення змінили workflow для мейкерів. [Посилання](https://makezine.com/article/technology/guide-to-boards-2026-no-computer-required/)
