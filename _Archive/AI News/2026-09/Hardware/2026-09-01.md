# Hardware / DIY Electronics Дайджест 2026-09-01

## Ключові тези
- ESP32 Bit Pirate v1.7 з LoRa і openbricks-прошивка для роботики — нові відкриті проєкти серпня 2026
- Arduino UNO Q (Qualcomm + STM32) і PiZZa (Arduino на Pi Zero 2 W) — два свіжих гібридні підходи для мейкерів
- Makera Z1 — краудфандинг на CNC з промисловою точністю ±0.02мм у форм-факторі для домашніх майстерень

## Новини
- **ESP32 Bit Pirate v1.7 з підтримкою LoRa** — Серпень 2026: ESP32 Bit Pirate оновлено до версії 1.7 — додано підтримку LoRa (SX1262), оболонку аналізу Meshtastic, BPIO2 (USB-інтерфейс апаратного управління), а також частотне сканування з RSSI-візуалізацією (waterfall-режим). [Джерело](https://www.opensourceforu.com/2026/08/esp32-bit-pirate-expands-open-source-hardware-debugging/)

- **ESPHome Starter Kit від Apollo Automation** — Apollo Automation запустила ESPHome Starter Kit на базі ESP32-C6: модульна платформа для розробки смарт-дому без паяння, макетних плат і написання коду — ідеальна для початківців у Home Assistant. [Джерело](https://blog.adafruit.com/2026/08/18/icymi-python-on-microcontrollers-newsletter-openbricks-your-esp32-robot-circuitpython-day-python-guitar-pedal-and-more)

- **openbricks: MicroPython-роботика на ESP32-S3** — openbricks — MIT-ліцензована MicroPython-прошивка для ESP32-S3, що реалізує Pybricks-подібний Python API для робототехніки на дешевому залізі: $15 serial-bus сервоприводи, SPI IMU, масиви датчиків відбиття. [Джерело](https://blog.adafruit.com/2026/08/18/icymi-python-on-microcontrollers-newsletter-openbricks-your-esp32-robot-circuitpython-day-python-guitar-pedal-and-more)

- **HomeMaster MiniPLC: ESP32 на DIN-рейці** — HomeMaster MiniPLC — компактний PLC-контролер на ESP32 у форм-факторі DIN-рейки з ESPHome і підтримкою Home Assistant; призначений для домашньої та легкої промислової автоматизації. [Джерело](https://news.tuxmachines.org/n/2026/08/15/Open_Hardware_Modding_Raspberry_Pi_5_ESP32_and_More.shtml)

- **ESP32-S31 отримує підтримку Linux** — Espressif анонсував Linux-підтримку для двоядерного RISC-V модуля ESP32-S31: представлений у березні 2026, дві плати розробника у травні, масове виробництво розпочато. Інтеграція Linux відкриває нові можливості для edge-computing. [Джерело](https://news.tuxmachines.org/n/2026/08/27/Open_Hardware_Modding_Raspberry_Pi_5_Banana_Pi_and_More.shtml)

- **PiZZa: Arduino-середовище прямо на Raspberry Pi Zero 2 W** — Проєкт PiZZa реалізує повноцінне Arduino IDE та середовище виконання прямо на Raspberry Pi Zero 2 W, поєднуючи зручність GPIO та потужність Linux у компактному форм-факторі. [Джерело](https://blog.adafruit.com/2026/07/01/pizza-arduino-on-the-raspberry-pi-zero-2-w/)

- **Arduino UNO Q: Qualcomm Linux + STM32 реального часу** — Arduino UNO Q — перша Arduino-плата, що запускає повноцінний Debian Linux на Qualcomm Dragonwing QRB2210, одночасно зберігаючи STM32U585 для задач реального часу. Оголошено у жовтні 2025, активно використовується у 2026. [Джерело](https://makezine.com/article/technology/guide-to-boards-2026-no-computer-required/)

- **Makera Z1: промислова CNC-точність для мейкерів** — Makera Z1 — краудфандинговий CNC-фрезер з точністю ±0.02 мм, автозміною інструментів та AI-асистованим CAM у повністю закритому корпусі, спроектований простим, як 3D-принтер. Орієнтований на домашні майстерні та малих виробників. [Джерело](https://backerrock.com/blogs/innovative/q2-2026-kickstarter-tech-trends-current-2026-projects)
