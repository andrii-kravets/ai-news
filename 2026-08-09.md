- Meta представила Muse Spark 1.2 та Muse Code — перший терміналний AI-агент компанії для кодування, побудований на базі оновленого флагмана
- DeepSeek V4-Flash встановив новий ціновий мінімум серед великих LLM: $0.14 за мільйон вхідних токенів при продуктивності рівня frontier mid-tier

- **Meta Muse Spark 1.2 + Muse Code** — 5 серпня Meta оновила флагман до версії 1.2 та одночасно випустила Muse Code — терміналний агент для кодування. Muse Spark 1.2 досягла Intelligence Index 54 при ціні $1.25/$4.25, посівши друге місце після Claude Opus 5 за оцінкою Artificial Analysis. [Детальніше](https://artificialanalysis.ai/changelog)

- **DeepSeek V4-Flash** — DeepSeek перенавчив V4-Flash з акцентом на кодування, AI-агентів та використання інструментів. Artificial Analysis визнав його найдешевшою великою моделлю у світі: $0.14/$0.28 за мільйон токенів при продуктивності рівня frontier mid-tier. [Детальніше](https://qz.com/deepseek-v4-flash-cheapest-ai-model-benchmark-080326)

- **Thinking Machines Inkling** — американська компанія Thinking Machines випустила Inkling — нову провідну open-weights модель зі США з дебютним результатом 41 на Artificial Analysis Intelligence Index. Перша публічна open-weights модель американського походження на цьому рівні якості. [Детальніше](https://artificialanalysis.ai/articles/thinking-machines-has-released-inkling-the-new-leading-u-s-open-weights-model)
