# AI Дайджест 2026-11-25

## Ключові тези
- Нью-Йорк підписав п'ятирічну заборону на продаж AI-чат-іграшок — другий штат після Каліфорнії, що обмежує дитячі AI-пристрої
- AMD завершила поглинання AI-чіп-стартапу Taalas приблизно за $3 млрд — посилення конкуренції з Nvidia на ринку спеціалізованих AI-прискорювачів
- Дослідники Oxford, MILA та Nvidia представили EGGROLL — метод тренування мільярдних нейромереж без зворотного поширення помилки

## Моделі та релізи

- **Z.ai GLM-5.4** (23–25 листопада) — 750B-параметрова модель на архітектурі Loop Transformer від компанії Z.ai; перший великий open-source Loop Transformer такого масштабу. API вже доступний, відкриті ваги заплановані на найближчі дні. [Джерело](https://daily.rclabs.in/day/2026-11-25)

- **Tencent Hunyuan OmniEVIE-4B** (24 листопада) — 4,5B multimodal retrieval-модель під ліцензією Apache 2.0; зайняла перше місце в бенчмарку MMEB (без урахування аудіо). Позиціонується як компактна основа для мультимодального пошуку. [Джерело](https://llm-stats.com/llm-updates)

- **PrismML Ternary Bonsai 2.5 27B** (25 листопада) — 27B-модель з тернарними вагами від PrismML; розроблена для ефективного локального запуску з мінімальними вимогами до пам'яті. [Джерело](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-november-25-2026/)

## Що стало безкоштовним / відкритим

- **Zyphra ZONOS3-Mini** (12 листопада, Apache 2.0) — open-weight модель для синтезу мовлення з клонуванням голосу, підтримує 43 мови; запускається локально безпосередньо у браузері без хмарного бекенду. [Джерело](https://www.nocode.mba/ai-release-tracker/2026/11)

- **Tencent Hunyuan OmniEVIE-4B** — повні відкриті ваги під Apache 2.0 опубліковані одночасно з релізом (детальніше вище).

## Агенти та інструменти

- **LangChain LangSmith Tool Gateway** (публічна бета, 19 листопада) — централізований шлюз для управління інструментами AI-агентів: зберігає облікові дані, реалізує політики доступу, потоки погодження та аудит-лог для кожного виклику. Підтримує MCP-сумісних клієнтів. Відрізняється від раніше оголошених managed sandboxes (ізоляція коду), оскільки фокусується на управлінні ідентичностями та дозволами. [Джерело](https://aiagentsdirectory.com/news/ai-agents-news-brief-november-18-2026)

- **Phylo Biomni Swarm** (25 листопада) — мультиагентна система від Phylo для спільної роботи над складними завданнями в біомедичних дослідженнях; позиціонується як перший спеціалізований рій для геноміки та протеоміки. [Джерело](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-november-25-2026/)

- **OpenAI + Cisco: AI-захист від вразливостей** (25 листопада) — спільний інструмент, який дозволяє AI-агентам в реальному часі виявляти та блокувати спроби експлуатації вразливостей у корпоративних мережах. Перший продукт OpenAI у категорії active network security. [Джерело](https://daily.rclabs.in/day/2026-11-25)

## Дослідження та бенчмарки

- **EGGROLL** (Oxford / MILA / Nvidia) — нова техніка тренування на основі еволюційних стратегій, що дозволяє навчати мільярдні мережі без backpropagation. Автори демонструють результати на рівні gradient-based методів при значно нижчих вимогах до диференційованості. [Джерело](https://agihunt.info/en/daily/2026-11-24)

## Фінансування та поглинання

- **AMD поглинула Taalas за ~$3 млрд** (близько 24 листопада) — придбання стартапу у сфері AI-прискорювачів дозволить AMD підсилити лінійку спеціалізованих чіпів для inference. Угода завершена; умови не розкриваються повністю. [Джерело](https://www.ai-market-watch.com/news/category/acquisition)

- **Embo: $110 млн seed від a16z** (листопад) — стартап «мозок для роботів» заснований Данієром Гафнером (ex-DeepMind, автор DreamerV3) та залучив стартовий раунд від Andreessen Horowitz. Компанія розробляє загальний когнітивний рівень для автономних систем. [Джерело](https://techstartups.com)

## Регуляція та безпека

- **Нью-Йорк: заборона AI-іграшок на 5 років** (25 листопада) — губернаторка Кеті Гоккул підписала закон, що забороняє виробництво і продаж іграшок із вбудованими AI-чат-ботами до 2031 року; набирає чинності у лютому. Нью-Йорк став другим штатом після Каліфорнії, що ввів такий захід. [Джерело](https://nbcnews.com/tech/tech-news/new-york-governor-kathy-hochul-sign-ai-toy-ban-law-rcna610962)

- **UK NCSC: попередження про AI-кіберзагрози** (25 листопада) — Національний центр кібербезпеки Великої Британії випустив офіційне попередження щодо зростання атак, де зловмисники використовують AI для автоматизації фішингу, розробки шкідливого ПЗ та розвідки. Перше таке попередження від NCSC за 2026 рік. [Джерело](https://daily.rclabs.in/day/2026-11-25)

- **UK FCA: AI-агенти під фінансовим регулюванням** (25 листопада) — британський регулятор фінансових ринків FCA дав зрозуміти, що автономні AI-агенти, які виконують фінансові операції, потрапляють під чинну регуляторну базу — без чекання нових законів. Це може вплинути на fintech-стартапи, що будують агентні платформи у Великій Британії. [Джерело](https://daily.rclabs.in/day/2026-11-25)
