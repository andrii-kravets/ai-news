## Моделі та релізи
- **Grok 4.7 (xAI, 21 вересня)** — найбільша модель xAI: 2.1 трлн параметрів (на 40% більше за Grok 4.6) за незмінною ціною $2/$6 за млн токенів та 500 K контекстним вікном. Особливість — додаткові тренувальні дані з SpaceX: телеметрія Starlink, виробничі журнали, інженерні звіти про відмови. xAI заявляє про посилений «ланцюжок перевірки» відповідей і сильніші safety-guardrails. Доступна без черги в Grok App, Cursor, Grok Build, xAI API та GitHub Copilot (Pro, Pro+, Max, Business, Enterprise). [Decrypt](https://decrypt.co/378824/xai-launches-grok-4-7) / [MarkTechPost](https://www.marktechpost.com/2026/09/21/spacexai-releases-grok-4-7/) / [GitHub Changelog](https://github.blog/changelog/2026-09-21-grok-4-7-is-now-available-in-github-copilot/)

## Інструменти та агенти
- **Google ADK for Kotlin 1.0 (9 вересня)** — Google оголосила про GA-реліз Agent Development Kit для Kotlin з повним паритетом із Python- та Java-версіями. Підтримує on-device-агентів через LiteRT-LM і ML Kit (beta), гібридні хмарні сценарії через Firebase AI Logic та збереження стану агента між перезапусками через Room і AppSearch. Платформа Kotlin Multiplatform (KMP) не прив'язана до конкретного backend-провайдера. [Google Developers Blog](https://developers.googleblog.com/announcing-adk-for-kotlin-10-building-production-ready-ai-agents-in-kotlin-android-and-beyond/) / [InfoQ](https://www.infoq.com/news/2026/09/google-adk-1-0-released/)

## Дослідження та бенчмарки
- **«Діапазон скорочується, загроза залишається» — LLM Package Hallucinations (arXiv 2605.17062)** — дослідники протестували 5 фронтирних моделей (Claude Sonnet 4.6, Claude Haiku 4.5, GPT-5.4-mini, Gemini 2.5 Pro, DeepSeek V3.2) на 199 845 Python- та JS-запитах. Частота галюцинацій пакетних імен: 4.62% (Haiku 4.5) — 6.10% (GPT-5.4-mini) — міжмодельний діапазон звузився на порядок проти попередніх когорт. Виявлено 127 «фантомних» пакетів, які всі 5 моделей вигадують однаково; після координованого розкриття з PyPI Security і Socket.dev 53 із них вже зареєстровано реальними акторами. [arXiv](https://arxiv.org/abs/2605.17062)

## Безпека та AI-спільнота
- **Даріо Амодей «We Must Pace the Frontier» (12 вересня)** — CEO Anthropic опублікував есей на 3 800 слів із трьохкроковим планом навмисного уповільнення розробки можливостей моделей: ① постійний employee-level доступ стороніх оцінювачів до систем лабораторій (Anthropic взяла зобов'язання unilaterally); ② цільове регулювання США, яке охоплює всі frontier-компанії; ③ глобальна координація, включно з Китаєм. Sam Altman (OpenAI), Elon Musk (xAI) та Demis Hassabis (DeepMind) публічно підтримали основну ідею протягом кількох годин. Ринкові котирування AI-компаній похитнулися на тлі невизначеності щодо темпів розробки. [darioamodei.com](https://darioamodei.com/post/we-must-pace-the-frontier) / [MindStudio](https://www.mindstudio.ai/blog/anthropic-pace-the-frontier-ai-labs) / [CNBC](https://www.cnbc.com/2026/09/13/china-dilemma-ai-slowdown-anthropic.html)

## Регулювання та політика
- **Каліфорнія: Ньюсом наказує розробити нові AI-правила (18 вересня)** — Губернатор Ньюсом підписав виконавче розпорядження, яким доручив агентствам штату підготувати законодавчі рекомендації: вимоги щодо зовнішніх safety-оцінювачів в AI-компаніях, незалежна верифікація safety-фреймворків, «кнопка вимкнення» для аварійної зупинки систем та розширення обов'язкового звітування про інциденти (включно з «втратою контролю» на кшталт нещодавніх хакингів). Це різка зміна курсу: два роки тому Ньюсом накладав вето на аналогічні вимоги SB 1047.
