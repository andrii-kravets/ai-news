# Indie Hacking / SaaS Дайджест 2026-11-05

## Ключові тези
- Листопад 2026 — насичений місяць для SaaS-спільноти: SaaS North (4–5 листопада), Web Summit (9–12 листопада), Slush (18–19 листопада)
- Великі гравці продовжують GA-релізи: Vercel Drives, Snowflake Semantic Studio, SAS CI360 MCP Server
- Статистика бутстрапінгу залишається жорсткою: ~70% мікро-SaaS засновників не виходять за $1K MRR

## Новини
- **SaaS North 2026** — конференція для масштабування SaaS-бізнесів пройшла 4–5 листопада в Оттаві. Одна з ключових подій осіннього SaaS-сезону в Північній Америці. [Founderpath Events](https://founderpath.com/events/saas/upcoming)
- **Vercel Drives GA** — 15 жовтня 2026 Vercel запустила в загальний доступ Drives — сервіс постійного зберігання для edge-деплойментів. Відповідь на попит від команд, що будують stateful-додатки. [blog.mean.ceo](https://blog.mean.ceo/ai-product-launches-news-november-2026/)
- **Snowflake Semantic Studio GA** — 30 вересня 2026 вийшов інструмент для семантичного шару даних у загальний доступ, спрощує роботу аналітиків без SQL. [blog.mean.ceo](https://blog.mean.ceo/ai-product-launches-news-november-2026/)
- **SAS CI360 MCP Server** — 2 листопада 2026 Model Context Protocol-сервер став доступний у production для всіх клієнтів SAS Customer Intelligence 360. Черговий великий вендор, що відкриває MCP-доступ до своїх даних. [SAS Communities](https://communities.sas.com/t5/SAS-Customer-Intelligence-360/What-s-New-for-CI360-in-November-2026/ba-p/995767)
- **Marvell купує Lumentum** — угода оголошена 2 листопада 2026, all-stock. Lumentum виробляє оптику для AI-дата-центрів; угода відображає зростаючий попит на AI-інфраструктуру. [SaaSrise Weekly](https://www.saasrise.com/blog/this-week-in-saas-ai-oct-27---nov-2-2026)
- **Web Summit 2026** — 9–12 листопада в Лісабоні, традиційна майданчик для анонсів стартапів і нетворкінгу. Очікуються нові продуктові запуски. [Founderpath Events](https://founderpath.com/events/saas/upcoming)
- **Статистика мікро-SaaS** — за даними трекерів 8000+ стартапів, середній активний мікро-SaaS має $4,298 MRR, але медіана лише $145. Близько 70% засновників залишаються нижче $1K MRR. [flowjam.com](https://www.flowjam.com/blog/27-micro-saas-examples-that-actually-print-money-in-2025)
- **Plausible Analytics** — відкритий аналітичний SaaS досяг ~$3.5M ARR з командою близько 10 осіб. Часто цитується як benchmark для bootstrapped B2B SaaS. [growpredictably.com](https://growpredictably.com/micro-saas-examples)
