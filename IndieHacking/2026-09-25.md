# Indie Hacking / SaaS Дайджест 2026-09-25

## Ключові тези
- Тиждень 15–21 вересня 2026: п'ять помітних SaaS-раундів від $10M до $114M — від manufacturing AI до fintech та нерухомості
- Вертикальний micro-SaaS перемагає у 2026: ніш-продукти для лендлордів, юристів, клінік дають кращий fit і нижчий churn
- Лише 18% micro-SaaS досягають «зони стійкості» $1K–$5K MRR, але «солодка зона» $5K–$50K ширша ніж будь-коли через дешеві API

## Новини
- **CADDi — $114M Series D** — 15 вересня 2026 японська AI-платформа для виробничої галузі закрила раунд Series D за оцінки $1.2 млрд. CADDi автоматизує закупівлі та ланцюги постачання для заводів. [Посилання](https://www.saasrise.com/blog/this-week-in-saas-september-15---21-2026)

- **Facilo — $41M Series B** — 17 вересня 2026 хмарна AI-платформа для брокерів нерухомості залучила $41M для масштабування воркфлоу та AI-аналітики угод. [Посилання](https://www.saasrise.com/blog/this-week-in-saas-september-15---21-2026)

- **Paymob — $35M Pre-Series C** — 21 вересня 2026 платіжна інфраструктура для Близького Сходу залучила раунд перед IPO-підготовкою з фокусом на розширення мерчант-бази по регіону. [Посилання](https://www.saasrise.com/blog/this-week-in-saas-september-15---21-2026)

- **Sprive — $10M Series A** — 21 вересня 2026 британський AI-fintech для оптимізації іпотечних виплат залучив $10M для виходу на нові ринки. [Посилання](https://www.saasrise.com/blog/this-week-in-saas-september-15---21-2026)

- **Finloop — $10M+ Series A+** — 15 вересня 2026 платформа digital wealth-management для банків залучила раунд Series A+ зі стратегічним інвестором HSBC. [Посилання](https://www.saasrise.com/blog/this-week-in-saas-september-15---21-2026)

- **Вертикальний micro-SaaS — тренд вересня 2026** — Аналітики фіксують: ніш-продукти для конкретних індустрій (лендлорди, медклініки, юридичні команди) демонструють кращий product-market fit і вищий retention порівняно з горизонтальними аналогами. [Посилання](https://blog.mean.ceo/micro-saas-trends-september-2026/)

- **Micro-SaaS: нові бенчмарки 2026** — Лише 18% micro-SaaS компаній досягають зони стійкості $1K–$5K MRR. Але «солодка зона» $5K–$50K стала ширшою через дешеві API та no-code-інструменти. Медіанний прибутковий продукт дає ~$4.2K MRR. [Посилання](https://www.saas-capital.com/blog-posts/benchmarking-metrics-for-bootstrapped-saas-companies/)
