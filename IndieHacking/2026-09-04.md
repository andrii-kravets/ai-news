# Indie Hacking / SaaS Дайджест 2026-09-04

## Ключові тези
- Micro-SaaS сектор зростає на 30% на рік: з $15,7 млрд у 2024 до прогнозованих $59,6 млрд до 2030
- Топові bootstrapped продукти 2026: Tally ($150K MRR), Rezi ($200K MRR), Typefully ($113K MRR)
- AI-асистенти для кодування скорочують час розробки на 50%, Supabase + Vercel + Stripe роблять запуск MVP тривіальним

## Новини

- **Micro-SaaS статистика 2026** — 70% micro-SaaS бізнесів заробляють менше $1K MRR. Лише 18% досягають зони стійкості ($1K–$5K MRR), і лише 11% виходять на $5K–$50K MRR. Середній дохід топ-продуктів — $83 300/місяць. [Джерело](https://www.shno.co/marketing-statistics/micro-saas-launch-statistics)

- **Tally: $150K MRR без зовнішніх інвестицій** — Bootstrapped конструктор форм Tally утримує $150K MRR у 2026 році, залишаючись повністю незалежним. Один із найчастіше цитованих прикладів успішного micro-SaaS. [Джерело](https://bigideasdb.com/micro-saas-examples-2026/)

- **Rezi: $200K MRR — AI-конструктор резюме** — Rezi досяг $200K MRR у 2026, займаючи нішу AI-оптимізованих резюме для пошукачів роботи. [Джерело](https://bigideasdb.com/micro-saas-examples-2026/)

- **Typefully перевищив $113K MRR** — Інструмент для авторів у соцмережах Typefully підтверджує нішеву модель: один сфокусований продукт для Twitter/X і LinkedIn без VC-фінансування. [Джерело](https://bigideasdb.com/micro-saas-examples-2026/)

- **Вертикальний SaaS зростає в 2–3 рази швидше** — За даними аналітиків, galactic SaaS (горизонтальні рішення) поступається нішевим вертикальним продуктам, які вирішують конкретні болі конкретної аудиторії. [Джерело](https://founderpath.com/blog/bootstrapping-startup)

- **IndieHunt — щотижнева платформа для запусків** — IndieHunt запускає нові продукти щопонеділка о 8:00 UTC. Конкурує з Product Hunt і BetaList як майданчик для indie-засновників. [Джерело](https://indiehunt.io/studio/best-weekly-launch-platforms-for-indie-hackers-2026-04-16)

- **Bootstrapped SaaS стек 2026** — Стандартний стек без VC: AI-асистент для кодування (знижує час розробки на 50%), Supabase для бекенду, Vercel для деплою, Stripe для біллінгу. Вхідний поріг ніколи не був нижчим. [Джерело](https://www.tldl.io/resources/indie-hacker-saas-stack-2026)

- **Рух indie hackers у 2026** — Десятки тисяч засновників будують SaaS, AI-інструменти та мікропродукти без венчурного капіталу. Рушійні сили: AI-інструменти, no-code, дистанційна робота та «розбундлювання» великих платформ. [Джерело](https://www.betterlaunch.co/blog/indie-hacker)
