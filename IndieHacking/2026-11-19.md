# Indie Hacking / SaaS Дайджест 2026-11-19

## Ключові тези
- Bustem досяг $8M ARR повністю bootstrapped менш ніж за 2 роки — один із найбільших підтверджених milestones листопада
- Product Hunt цього тижня очолив Kilo Code v7 — інструмент для VS Code з паралельними агентами та diff-рев'ювером
- ElevenLabs виходить у B2B-SaaS: ElevenAI може стати конкурентом для Granola, Fathom та Fireflies

## Новини

- **Bustem: $8M ARR, повністю bootstrapped** — засновник Олівер Брокато підтвердив 14 листопада 2026, що Bustem досяг $8 млн річного доходу без зовнішнього фінансування менш ніж за два роки. [Джерело](https://www.arr.club/bustem/bustem-hit-8m-arr-fully-bootstrapped-in-under-two-years)

- **Kilo Code v7 — #1 на Product Hunt** — нова версія AI-кодинг розширення для VS Code отримала паралельних агентів, diff-рев'ювер і порівняння моделей. Одна з найбільш відмічених позицій тижня на платформі. [Джерело](https://www.producthunt.com/)

- **Denovo** — інструмент для автоматизації бізнес-процесів з позиціонуванням «будуй і керуй бізнесом уві сні». З'явився у топі Product Hunt цього тижня. [Джерело](https://www.producthunt.com/)

- **Spellar 3.0** — AI-компаньйон для зустрічей, нова версія вийшла у листопаді 2026; конкурує з Granola та Fathom у сегменті meeting notes. [Джерело](https://www.producthunt.com/)

- **HasData** — сервіс веб-скрапінгу для AI-агентів, також у топі Product Hunt цього тижня. [Джерело](https://www.producthunt.com/)

- **ElevenAI (ElevenLabs)** — 13 листопада TechCrunch написав про вихід ElevenLabs на ринок B2B-продуктивності: застосунок для нотаток зустрічей та диктування для команд. Прямий виклик для bootstrapped niche гравців (Granola, Fathom, Fireflies). [Джерело](https://techcrunch.com/2026/11/13/elevenlabs-new-app-combines-meeting-note-taking-and-dictation-for-teams/)

- **Статистика micro-SaaS за листопад 2026** — медіана по ринку залишається ~$145 MRR; лише 6,1% продуктів перевищує $10K MRR. Топ-6% ринку генерує непропорційно великий дохід. [Джерело](https://bigideasdb.com/micro-saas-examples-2026)
