# Продуктивність / PKM Дайджест 2026-11-09

## Ключові тези
- Tana розділився на два продукти у квітні 2026: новий agentic-продукт для зустрічей (tana.inc) і Tana Outliner (outliner.tana.inc); у листопаді на Outliner доступні голос і MCP-інтеграції
- Obsidian став де-факто стандартом для «second brain з AI»: markdown-файли читаються зовнішніми AI-інструментами без плагінів
- Самохостинг у PKM набирає обертів: Blinko та Memos — open-source альтернативи для тих, хто не хоче хмари

## Новини
- **Tana: розподіл на два продукти** — У квітні 2026 команда анонсувала новий agentic-продукт для зустрічей на tana.inc (мобільний пріоритет, SOC 2 + GDPR), тоді як класичний Outliner переїхав на outliner.tana.inc. HIPAA очікується у наступні місяці після запуску. [Tana Blog](https://outliner.tana.inc/blog/tana-current-april-2026)
- **Tana Outliner + MCP** — Оновлення початку 2026 додало голосовий чат на Android і підтримку MCP (Model Context Protocol) для підключення AI-кодінг-асистентів на зразок Claude Code. Поля можна оновлювати програмно. [Tana Releases](https://outliner.tana.inc/releases/2026-wk-02-03)
- **Obsidian як ядро second brain** — Аналітики відзначають: Obsidian лідирує у listopad-2026 рейтингах «AI second brain» саме завдяки plain markdown — зовнішні AI-інструменти читають vault без плагінів та експорту. [Taskade Blog](https://www.taskade.com/blog/ai-second-brain-tools)
- **Capacities** — Object-based PKM, де кожен запис є структурованим «об'єктом» з типом і зв'язками. Регулярно з'являється у листопадових оглядах як альтернатива для тих, кому не підходять плоскі нотатки Obsidian. [ToolFinder](https://toolfinder.com/best/second-brain-apps)
- **Saner.AI** — AI-first PKM з автоматичним тегуванням і зв'язками; виходить у листопадових топах 2026. Акцент на мінімальному введенні з боку користувача: AI будує структуру самостійно. [Saner.AI Blog](https://www.saner.ai/blogs/10-best-second-brain-ai-apps)
- **Blinko** — Open-source, self-hosted PKM: підтримує markdown, теги та AI-пошук. Позиціонується для тих, хто хоче повний контроль над даними без SaaS-підписок. [Awesome Second Brain](https://github.com/Mindola-ai/awesome-second-brain)
- **Memos** — Ще один self-hosted варіант: мінімалістичний, з REST API і підтримкою Markdown. Присутній у кількох листопадових порівняннях для приватних нотаток. [Awesome Second Brain](https://github.com/Mindola-ai/awesome-second-brain)
