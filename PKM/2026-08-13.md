# Продуктивність / PKM Дайджест 2026-08-13

## Ключові тези
- Obsidian отримав переосмислену панель налаштувань та пошук по Settings — найпомітніше UX-оновлення інтерфейсу за 2026 рік
- AI у PKM перейшов від «допоміжного» до основного рушія: семантичний пошук та агенти замінюють ручну організацію
- «Second Brain for AI» на базі Cloudflare — постійна пам'ять для Claude, ChatGPT та Cursor — активно обговорюється у спільноті

## Новини
- **Obsidian: оновлений Settings із пошуком** — Нова версія Obsidian отримала повністю перероблену панель налаштувань із вбудованим пошуком по опціях, а також зміни у Restricted Mode та рендерингу Mermaid-діаграм. [Посилання](https://obsidian.md/blog/future-of-plugins/)

- **Obsidian CLI — стабільний випуск** — Утиліта командного рядка для автоматизації операцій зі сховищем Obsidian, яка вийшла для Insider раніше в 2026, досягла загальної доступності. Дозволяє керувати vault зі скриптів та CI. [Посилання](https://www.dsebastien.net/the-must-have-obsidian-plugins-for-2026/)

- **Топ-5 AI-плагінів Obsidian у 2026** — Smart Connections, Copilot, Smart Composer, Text Generator та Local GPT визначені найефективнішими для AI-роботи у vault. Усі підтримують локальні та хмарні моделі. [Посилання](https://www.shadow.do/blog/best-ai-plugins-for-obsidian-2026)

- **Arduino VENTUNO Q — Obsidian для hardware** — Новий плагін PiZZa дозволяє запускати Arduino-середовище прямо на Raspberry Pi Zero 2 W, що спрощує прототипування без окремого MCU-пристрою. [Посилання](https://blog.adafruit.com/2026/07/01/pizza-arduino-on-the-raspberry-pi-zero-2-w/)

- **«Second Brain for AI» — безкоштовний інструмент на Product Hunt** — Сервіс надає постійну пам'ять для Claude, ChatGPT та Cursor, побудований на Cloudflare Workers. Позиціонується як «відсутній шар пам'яті» для LLM-помічників. [Посилання](https://www.producthunt.com/products/second-brain-cloudflare)

- **PKM 2026: рекомендації за профілем користувача** — Tana — для просунутих із нелінійним мисленням, Logseq — для студентів і дослідників, Reflect — для зайнятих професіоналів, Notion+AI — для корпоративних команд. [Посилання](https://yaranga.net/blog/pkms_personal_use_2026/)

- **Taskade — PKM із замкненим AI-циклом** — Платформа автоматично перетворює захоплені нотатки на workflow, завдання та live-дашборди без ручних кроків. Визначена найкращою для «notes to action». [Посилання](https://www.taskade.com/blog/ai-second-brain-tools)

- **Стаття: «Кінець PKM-інструментів»** — Матеріал у Medium (квітень 2026) стверджує, що 2026-й рік є переломним: переможці — системи, що думають замість вас, а не просто зберігають дані. [Посилання](https://paco-cantero.medium.com/the-end-of-pkm-tools-build-a-productivity-system-that-thinks-fa3118284673)

- **AFFiNE — відкрита альтернатива Notion** — Мультимодальна платформа (текст + канвас + бази даних) розширила AI-можливості у 2026 і зростає як open-source конкурент у ніші Second Brain. [Посилання](https://affine.pro/blog/best-second-brain-apps)
