# Продуктивність / PKM Дайджест 2026-08-23

## Ключові тези
- Logseq 2.0 DB beta + синхронізація RTC стали доступні для всіх активних щомісячних бекерів — суттєве розширення доступу до нового ядра
- Tana Outliner Remote MCP дозволяє різним версіям Tana взаємодіяти через протокол; проєкт Vellum наближається до релізу
- FSRS витісняє SM-2 як стандарт SRS — Anki, RemNote, Mochi вже перейшли; з'являються нові ніші: Chunks для гуманітарних дисциплін, Recall для AI+SRS

## Новини
- **Logseq 2.0 DB beta + RTC sync — для всіх бекерів** — Функції Logseq 2.0, включно з DB-бетою та синхронізацією в реальному часі (RTC), відкрито для всіх активних щомісячних бекерів. Це ключовий крок перед повним публічним релізом переписаного ядра на базі даних, що замінить файлову структуру Markdown. [Посилання](https://tana.inc/blog/best-pkm-tools-2026)

- **Tana Outliner Remote MCP випущено** — Команда Tana випустила Tana Outliner Remote MCP — перший протокол, що дозволяє різним версіям продукту (Tana і Tana Outliner) обмінюватися даними і командами. Відкриває нові інтеграції з AI-агентами. [Посилання](https://tana.inc/blog/best-pkm-tools-2026)

- **Vellum від Tana наближається до релізу** — Проєкт Vellum з екосистеми Tana виходить у фінальну фазу розробки і «виглядає дуже добре» за словами команди. Деталі функціоналу поки не розкриваються. [Посилання](https://tana.inc/blog/best-pkm-tools-2026)

- **Recall.it: AI-резюме + активне відтворення + SRS** — Recall дозволяє зберігати відеолекції, PDF та нотатки, автоматично генерує тести для активного відтворення і будує SRS-розклад для довгострокового запам'ятовування. Позиціонується як гібрид між AI-нотатником і Anki — без потреби вручну створювати картки. [Посилання](https://www.recall.it/compare)

- **Chunks.app: SRS без побудови колод для гуманітарних предметів** — Chunks спеціалізується на гуманітарних дисциплінах: AI автоматично генерує флеш-картки з контенту без ручної побудови колод. У 2026 увійшов до рейтингу кращих SRS-застосунків поряд з Anki і RemNote. [Посилання](https://chunks.app/blog/best-spaced-repetition-apps-2026)

- **FSRS витісняє SM-2 як де-факто стандарт** — Більшість провідних SRS-застосунків у 2026 році (Anki, Mochi, RemNote) перейшли або переходять на FSRS замість SM-2. Для більшості студентів FSRS-застосунок стає рекомендованим вибором за замовчуванням. [Посилання](https://studyglen.com/guides/best-spaced-repetition-apps)

- **Wispr Flow Notetaker — вихід за межі диктування** — 5 серпня 2026 Wispr Flow, відома насамперед своїм диктофонним AI-продуктом, випустила Notetaker — перший AI-нотатник для зустрічей від команди. Використовує контекст з календаря та підключених застосунків для точніших підсумків. [Посилання](https://9to5mac.com/2026/08/05/wispr-flow-takes-on-ai-meeting-assistants-with-notetaker-its-first-product-beyond-dictation/)
