# PKM / Продуктивність Дайджест 2026-08-29

## Ключові тези
- Obsidian v1.13.6 і v1.13.7 (7–12 серпня) вийшли у швидкому темпі; спільнота генерує ~238 нових плагінів на тиждень — Sync Engine, Community Install Manager, Journal View
- Notion (19 серпня) додав Developer-секцію і AI model picker зі скоркартами: швидкість, інтелект, вартість
- Підхід Claude Code + Obsidian vault набирає популярності у 2026 як спосіб побудувати AI-second brain без хмари та ручного файлування

## Новини

- **Obsidian Desktop v1.13.6 та v1.13.7 — серпневі патчі (7–12 серпня 2026)** — v1.13.6 оновив слайдери в налаштуваннях до акцентного кольору; v1.13.7 виправив обробку спецсимволів у назвах файлів на macOS. Обидва релізи вийшли протягом одного тижня, підтримуючи стабільний темп оновлень. [Obsidian Changelog](https://obsidian.md/changelog/)

- **238 нових плагінів за тиждень 2–8 серпня: Sync Engine, Community Install Manager, Journal View** — Серед найцікавіших: Sync Engine — модульна синхронізація vault через WebDAV або S3; Community Install Manager — встановлення плагінів із JSON-файлу, що лежить у vault; Journal View — усі щоденні нотатки в єдиній хронологічній стрічці без ручного переходу між файлами. Загалом зафіксовано 899 оновлень наявних плагінів. [Obsidian Plugin Stats](https://obsidianpluginstats.substack.com/p/obsidian-plugin-updates-02-to-08)

- **Claude Code + Obsidian: self-organizing AI second brain без хмари** — У 2026 набирає обертів підхід: вказати Claude Code на Obsidian vault, додати CLAUDE.md і memory note — і отримати AI-асистента, що читає та пише нотатки. Безкоштовний плагін реалізує 15 skills на чистому Markdown. Перевага — повна локальність і власний контроль над даними без підписки на хмарний AI-сервіс. [NxCode Guide](https://www.nxcode.io/resources/news/obsidian-ai-second-brain-complete-guide-2026)

- **Obsidian: 1.5 млн користувачів, +22% рік до року (лютий 2026)** — Мілстоун підтверджено: зростання пояснюється поєднанням local-first архітектури з гнучкістю vault для AI-шару. Дані підкреслюють, що Obsidian перетворюється на «платформу» для PKM-екосистеми, а не просто застосунок для нотаток. [Shadow.do](https://www.shadow.do/blog/best-ai-plugins-for-obsidian-2026)

- **Notion: Developer-секція та AI model picker зі скоркартами (19 серпня 2026)** — Notion додав Developer section у налаштуваннях workspace: управління Workers, з'єднаннями та персональними токенами доступу; dev bar для миттєвого копіювання ID сторінок, баз і блоків. Паралельно оновлено AI model picker — скоркарти порівнюють моделі за швидкістю, інтелектом і вартістю, улюблені можна закріпити. [Releasebot Notion](https://releasebot.io/updates/notion)
