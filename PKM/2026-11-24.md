# Продуктивність / PKM Дайджест 2026-11-24

## Ключові тези
- Obsidian 1.15.1 вийшов і на мобільних (12 листопада) — той самий Relevance sort і новий Web Viewer core plugin
- Нова хвиля community-плагінів листопада: Git Note History, Vault Inspector, Full Calendar Remastered
- Ринок PKM у 2026 розколовся між local-first (Anytype, Logseq) та cloud-SaaS (Notion, Tana) — ніхто не лідирує однозначно

## Новини
- **Obsidian 1.15.1 Mobile (12 листопада 2026)** — Мобільна версія наздогнала desktop: Relevance sort для пошуку, виправлення відображення у Community plugins при відсутньому імені плагіна. Синхронізація функцій між desktop і mobile прискорилась у другій половині 2026 р. [Obsidian Changelog Mobile](https://obsidian.md/changelog/2026-11-12-mobile-v1.15.1/)
- **Web Viewer — новий core plugin Obsidian 1.15.1** — Вбудований браузер прямо у vault: при увімкненні опції «Open external links» посилання відкриваються у боковій панелі без виходу в зовнішній браузер. Корисно для роботи з онлайн-довідниками без переривання потоку. [Obsidian Changelog](https://obsidian.md/changelog/2026-11-12-desktop-v1.15.1/)
- **Git Note History — новий community plugin** — Відстежує, коли конкретне речення зникло з нотатки через git-коміт. Корисно для тих, хто використовує Git як версіювання vault і хоче знати, де «зникли» старі думки. [Obsidian Forum](https://forum.obsidian.md/tag/plugin-release/76)
- **Vault Inspector — новий community plugin** — Знаходить зламані посилання та «осиротілі» вкладення у vault. Технічний огляд здоров'я бази знань: дозволяє виявити, що давно «зависло» і не пов'язане з рештою. [Obsidian Forum](https://forum.obsidian.md/tag/plugin-release/76)
- **«7 PKM Tools vs 1 That Does It All» (5 листопада 2026)** — Стаття Yaranga ділить інструменти на дві групи: graph-based (Obsidian, Logseq, Tana, Heptabase, Anytype, Roam Research) і «все в одному» (Notion, ClickUp). Висновок: не існує одного переможця — підхід залежить від того, як людина думає і що хоче відстежувати. [Yaranga](https://yaranga.net/articles/2026-11-05-7-pkm-tools-vs-1-that-does-it-all-in-2026)
- **Local-first vs Cloud: великий розкол 2026** — Anytype та Logseq роблять ставку на P2P та локальне зберігання без хмари; Notion, Tana та Reflect — повністю хмарні. Для команд із вимогами конфіденційності або постійною офлайн-роботою local-first стає вагомим аргументом, тоді як хмарні рішення виграють у AI-інтеграції. [Deep Dive, травень 2026](https://www.youngju.dev/blog/culture/2026-05-15-pkm-tools-2026-notion-obsidian-logseq-anytype-tana-capacities-heptabase-deep-dive.en)
