# PKM / Продуктивність Дайджест 2026-11-17

## Ключові тези
- Obsidian v1.15.1 (3 листопада): новий Relevance sort для пошуку нотаток і підтримка widget-ів у мобільному застосунку
- Листопадова хвиля плагінів Obsidian: 10+ нових розширень за 1–5 листопада — акцент на SRS, презентаціях та академічній роботі
- ZotLit v2 виходить на перший план як нова точка інтеграції Obsidian + Zotero для академічної PKM

## Новини

- **Obsidian v1.15.1** — реліз від 3 листопада 2026 для desktop і mobile. Desktop: додано опцію «Relevance sort» у пошуку — результати впорядковуються за релевантністю запиту, а не за датою. Mobile: нові widget-и можна відкривати у новій вкладці. [Changelog Desktop](https://obsidian.md/changelog/2026-11-03-desktop-v1.15.1/) | [Changelog Mobile](https://obsidian.md/changelog/2026-11-03-mobile-v1.15.1/)

- **Ray Notes** — новий плагін для Obsidian у стилі Raycast: плаваюче вікно нотаток поверх будь-якого вікна, клавіатурні скорочення для швидкого захоплення. Оголошено на форумі Obsidian 5 листопада 2026. [Obsidian Forum](https://forum.obsidian.md/tag/plugin-release/76)

- **ZotLit v2** — масштабне оновлення плагіна інтеграції Obsidian + Zotero. Вийшло 4 листопада. Прискорює академічний PKM-воркфлоу: імпорт анотацій, посилань і нотаток із Zotero безпосередньо у Vault. [Obsidian Forum](https://forum.obsidian.md/tag/plugin-release/76)

- **Synclo** — плагін для Obsidian, що перетворює нотатку на презентацію для експорту у PowerPoint або PDF. Анонсований 3 листопада. Дозволяє готувати слайди прямо з Markdown-нотаток без зовнішніх інструментів. [Obsidian Forum](https://forum.obsidian.md/tag/plugin-release/76)

- **Rehearse** — плагін спaced-repetition для Obsidian (1 листопада). Перетворює нотатки на картки для повторення без ручного створення декс. Альтернатива Recall і RemNote для тих, хто хоче SRS прямо у своєму Vault. [Obsidian Forum](https://forum.obsidian.md/tag/plugin-release/76)

- **Full Calendar Remastered** — оновлений календарний плагін для Obsidian з підтримкою CalDAV і Google Calendar (1 листопада). Local-first підхід: усі дані зберігаються у Vault, синхронізація опційна. [Obsidian Forum](https://forum.obsidian.md/tag/plugin-release/76)

- **Git Note History** — плагін для перегляду видалених речень і відновлення тексту з git-коміт-архіву (3 листопада). Корисний для довгострокових knowledge base, що зберігаються у git-репозиторії. [Obsidian Forum](https://forum.obsidian.md/tag/plugin-release/76)

- **Wispr Flow Notetaker** — Wispr Flow (відомий диктофонний інструмент) вийшов за межі диктування і запустив AI notetaker для зустрічей (серпень 2026). Транскрипція + резюме Zoom-зустрічей, конкурент Granola, Otter.ai і Fireflies. Ринок AI-нотаток для мітингів стає все більш конкурентним. [AlternativeTo](https://alternativeto.net/news/2026/8/wispr-flow-launches-a-new-ai-notetaker-meeting-assistant-for-transcription-and-summaries/)
