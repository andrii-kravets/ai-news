# Продуктивність / PKM Дайджест 2026-11-07

## Ключові тези
- Obsidian 1.15.0 вийшов 2 листопада для desktop і mobile: пришвидшено завантаження плагінів, додано PDF-експорт та голосове захоплення на iOS 26
- Нові community-плагіни: Vault Inspector, ZotLit v2, StoryLine та Rehearse — активні пости на форумі наприкінці жовтня — на початку листопада
- Mem 2.0 перезапустився як персональний AI-асистент для нотаток; NotebookLM перейшов на Gemini 3.5 (червень 2026)

## Новини
- **Obsidian 1.15.0 Desktop + Mobile** — Вийшов 2 листопада 2026. Desktop прискорив завантаження community-плагінів; Mobile додав PDF-експорт та голосове захоплення у Quick Capture для iOS 26. [Changelog](https://obsidian.md/changelog/2026-11-02-desktop-v1.15.0/)
- **Vault Inspector** — Новий community-плагін для Obsidian: знаходить «зламані» посилання та осиротілі вкладення у vault. Опублікований наприкінці жовтня 2026. [Forum](https://forum.obsidian.md/c/share-showcase/plugins/22)
- **ZotLit v2** — Оновлена інтеграція Obsidian із Zotero для управління академічними джерелами. [Forum](https://forum.obsidian.md/c/share-showcase/plugins/22)
- **Rehearse** — Плагін Obsidian, що перетворює нотатки на flashcards для інтервального повторення. [Forum](https://forum.obsidian.md/c/share-showcase/plugins/22)
- **StoryLine** — Плагін для письменників у Obsidian: управління сюжетом та персонажами просто у vault. Набрав найбільше активності на форумі на початку листопада. [Forum](https://forum.obsidian.md/c/share-showcase/plugins/22)
- **Advanced Canvas 7.1.1** — Оновлення популярного плагіну для Canvas у Obsidian вийшло у тиждень 25–31 жовтня 2026. [ObsidianStats](https://www.obsidianstats.com/posts/2026-11-02-weekly-updates)
- **Mem 2.0** — Перезапуск на початку 2026 як AI-персональний асистент для нотаток: автоматично структурує та шукає інформацію у базі знань. [Tana Blog](https://tana.inc/blog/best-ai-note-taking-apps-2026)
- **NotebookLM** — Станом на червень 2026 переведено на модель Gemini 3.5, що покращило якість синтезу джерел. [Wikipedia](https://en.wikipedia.org/wiki/NotebookLM)
- **Granola** — Набирає популярності як локальний AI-нотатник для зустрічей на Mac без бота у дзвінку, зберігає приватність. [Metaview Blog](https://www.metaview.ai/resources/blog/ai-notetaking-apps)
