      **Опис:**
      Відео від каналу **CtrlD** демонструє процес створення власного вузла для мережі **Meshtastic** на базі **ESP32**. Основні теми:
      - **Що таке Meshtastic?** (децентралізована мережа без Wi-Fi, використовує LoRa/WAN).
      - **Чому не рація?** (використання SDR для радіомоніторингу).
      - **Етапи збірки:** вибір компонентів, установка прошивки, настройка PIN-коду через UART.
      - **Додаткові посилання:** GitHub репозиторій, сайт проєкту, українська документація, онлайн-мапа вузлів.

      **Технологічний інтерес:**
      - Обхід WiFi-мережі ESP32 для читання I/Q семплів з FR частини (SDR).
      - Розробка веб-інтерфейсу на ESP32 для SDR-аналізу.
      - Приклад використання **ESP32 + SX1278 LoRa модуля** для створення автономних ретрансляторів.

      **Практична цінність:**
      - Навчання пошуку компонентів, настройці прошивки та інтеграції SDR у децентралізовану мережу.
